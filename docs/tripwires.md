# Architectural tripwires

"Do not do X — here's why it broke before." Numbers are permanent: code comments cite them. CLAUDE.md carries one line per row; this file carries the why and the enforcement. When a census exists, its failure message states the rule too.

**Census keys follow types, not files.** Where a rule is about a type, its allow-list or counted list keys it `type:<TypeName>` — every file declaring that type, resolved by `SourceTree` (`MaughamTests/TestSupport/SourceTree.swift`) before the walk — so splitting a type across files never weakens the census, and a key that resolves to no file fails. A bare file name is used only where the rule is about one file. The canvas surface (`CanvasSourceCensus.surfaceFiles`) is a file list derived and checked against the types `CanvasView` builds, so a missing or stale entry fails. "Per file" in a row below means per key.
