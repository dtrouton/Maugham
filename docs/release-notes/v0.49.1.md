# Maugham 0.49.1

_Released YYYY-MM-DD_

_Mac only: the phone app is unchanged._

## What's new

- **To resolve's head folds, and the list gets the room.** The passes, the latest letter, the round's and the check's settings and both Ask about… fields used to fill most of the column above what's waiting on you. Now the head is folded until you open it: the chapter's name and where it stands (*Revising · Line in progress*), **Run Round** and **Reread**, and one line only when there's something to say — a run in progress, which always shows while it runs, a failure, the pass-order nudge, or the latest letter (*Letter from Lish · 2 hours ago*; click it to open the head). The chevron at the end of the first row opens and folds it, and the window remembers your choice. When the window is short, the open head scrolls within itself so the list never disappears. A translated edition's head and a chapter read in a language fold the same way. ⌘R, ⌃⌘R, ⇧⌘R and File ▸ Translate… work as before; Translate opens the head to answer.
