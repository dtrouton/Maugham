# Maugham 0.49.1

_Released YYYY-MM-DD_

_Mac only: the phone app is unchanged._

## What's new

- **To resolve's head folds, and the list gets the room.** The passes, the latest letter, the round's and the check's settings and both Ask about… fields used to fill most of the column above what's waiting on you. Now the head is folded until you open it: where the chapter stands (*Revising · Line in progress*) — with its name only when it isn't the chapter you have open — then **Run Round** and **Check Writing** (or **Reread** once it has been checked), and one line only when there's something to say: a run in progress, which always shows while it runs, a failure, a check that found nothing new, the latest letter (*Letter from Lish · 2 hours ago*; click it to open the head), the pass-order nudge, or what you've asked about. The chevron at the end of the first row opens and folds it, and the window remembers your choice. When the window is short, the open head scrolls within itself so the list never disappears. A translated edition's head and a chapter read in a language fold the same way. Every key works as before, and File ▸ Translate… is answered with the head folded.
- **A shorter row above the list.** New To-Do and Select Notes now live in one **…** menu at the end of the filter chips, so that row stays one line in a narrow column.
- **Short lists drop their group headers.** Under five items, each item carries a small caption saying where it sits instead, so a list of three things takes three rows, not six. The note that a list may still be loading rides on the first line rather than taking a row of its own.

## Fixes

- **New To-Do's Cancel button is no longer cut to "Ca…".** The scope choice and the buttons now sit on separate rows.
