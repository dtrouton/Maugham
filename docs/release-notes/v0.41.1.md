# Maugham 0.41.1

_Released 2026-09-27_

A fix to how People & Devices shows a book you write alone. Mac only; MaughamPhone 0.14.0 is unchanged.

## Fixes

- **One person, every device beneath them.** A person admitted on more than one device (your Mac and your iPhone, say) used to appear once per device, each under the same name. They now appear once, with each device listed under them. **Change…** sits on the person; **Rename…**, **Revoke** and **Re-admit** act on the device they're beside.
- **A device that hasn't described itself yet** is listed under its code with a plain sentence, rather than as a second copy of you. It gets its name the next time it writes in the book.
- **Older history is one quiet row.** Books started before Maugham signed its lines listed a warning for each old history file (and named one of them after a document). They're now a single row, *Older history from before this book signed its lines*, that says what it holds and that nothing already in it will change.
