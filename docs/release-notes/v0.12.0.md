# Maugham 0.12.0

_Released 2026-06-16_

An onboarding release. Everything Maugham can do was already here — this
release is about meeting it. A first-run tour, hands-on sample projects, a
built-in help library, and a README written for writers instead of builders.

## What's new

- **A welcome tour on first launch.** Open Maugham for the first time and an
  eight-card tour walks you through what it's for — focus writing, structure,
  organising a long manuscript, writing alongside Claude, publishing, and the
  fact that nothing is ever lost. Skip it anytime; reopen it whenever from
  **Help → Welcome to Maugham**.

- **Try it without committing.** The tour ends with a choice: open a real,
  fully editable **sample Novel** or **sample Screenplay**. The sample's own
  chapters walk you through the features — type here, press ⌘\ for focus,
  open the Outline, check off a to-do — and you can delete it the moment
  you're done. Grab a fresh one anytime from **Help → Sample Projects**.

- **A help library inside the app.** **Help → Maugham Help** (⌘?) opens a
  browsable guide — getting started, the editor, the binder, research, the
  right pane, screenplays, tasks, writing with Claude, publishing, and a
  reference of every shortcut. The same guide now lives at `docs/guide/` on
  GitHub.

- **Claude can answer "how do I…?"** A new `get_help` tool lets Claude
  Desktop read Maugham's own documentation, so you can ask it how to do
  something in Maugham and get an answer grounded in the actual guide.

- **To-dos, surfaced.** The sample and the new guide both show off task
  management — start any line with `- [ ]` and Maugham collects every
  checkbox across your project in the Tasks pane (⌘⌥5), alongside standalone
  tasks you add yourself.

## Notes

- Editing, sealing, history, sync, backups, publishing, and the iPhone
  companion are unchanged from 0.11.0.
- The tour's illustrations are drawn in-app for now; richer screenshots may
  follow in a later release.
