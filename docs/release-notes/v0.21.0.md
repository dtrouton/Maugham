# Maugham 0.21.0

_Released 2026-07-12_

A quiet release, by design. No new panes, no new tools — just a deep pass
over the machinery underneath, so the things you already rely on hold
firmer. Most of this you'll never notice, which is the point. A few of it
you will.

## What you'll notice

- **The update progress bar actually moves.** Downloading an update now
  shows real progress instead of sitting at zero until it finishes.
- **Your work survives the edges.** Toggling a task done and quitting
  immediately no longer risks losing that toggle; typing while another
  device syncs in no longer risks losing the words you were mid-sentence
  on; and ⌘Z keeps its history through a sync that only appends.
- **Palette rename is solid.** Renaming a palette card and then editing it
  no longer reverts the rename.

## Under the hood

- Correctness hardening across the op-log sync path, task and annotation
  undo, and the palette round-trip — the areas a maintainability review
  flagged, fixed and pinned with tests.
- Claude's document reads are faster and can't stall the editor on a large
  manuscript; oversized responses fail cleanly instead of silently.
- The first Claude request after relaunching Maugham no longer errors —
  the reconnect timing bug is fixed.
- Sundry robustness: safer file-path handling, bounded decompression of
  synced history, and a pinned, checksum-verified release toolchain.

## Compatibility

- Pairs with **MaughamPhone 0.7.0**. No manuscript, op-log, or schema
  format change — projects and cross-device sync are fully compatible
  with 0.20.0 in both directions.
