# Maugham 0.2.2

_Released 2026-05-23_

CI tooling fix. No functional changes — same code as v0.2.1, built against a newer macOS SDK.

## Fixes

- **Installed Maugham now matches the developer-machine rendering.** v0.2.1 was built on CI with Xcode 16.1 / macOS 15 SDK, while the developer machine uses Xcode 17 / macOS 26 SDK. SwiftUI's selection-state styling — segmented controls (Pieces tab, Draft status segment), inspector tab highlights, list-row selections — renders prominently in the macOS 26 SDK ("Liquid Glass" idiom) and flatter in older SDKs. Same source code, different chrome. Bumped CI to `macos-15` runner with `latest-stable` Xcode so installed builds track the same SDK as local builds.

## Known issues

- First open of each downloaded `.dmg` still requires right-click → Open in Privacy & Security. Will go away when we flip to signed + notarized builds.
