# Maugham 0.12.2

_Released 2026-06-26_

A focused bug-fix release that smooths out a few rough edges in the editor — all
caught in real writing sessions.

## Fixes

- **Emphasis no longer flickers while you edit.** Adding a word to the end of an
  *italic* or **bold** phrase used to make the styling flash off and back on with
  every keystroke. Styling now settles a beat after you stop typing, so it stays
  calm while you write. (Markdown still means exactly what it always did — only
  the *timing* of the on-screen styling changed.)

- **Typing on the last line no longer jolts the page.** Pressing space at the end
  of the document could make the view recoil or jump around. It stays put now.

- **The page follows your cursor near the bottom.** When you were typing close to
  the bottom edge with more text below, the view could fail to scroll and let the
  cursor run off-screen. It now keeps the cursor in view.

- **The cursor is the right height on a blank line.** An empty line showed an
  oversized caret that shrank the instant you typed a character. It now matches
  the height of your text.

## Notes

- No changes to your manuscripts, sync, publishing, or the iPhone companion since
  0.12.1.
