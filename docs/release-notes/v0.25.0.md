# Maugham 0.25.0

_Released 2026-07-23_

Publishing grew up around the first real books. Making *Playlist, Volume
One* — and its Spanish edition — through the pipeline surfaced every place
the tooling made you leave Maugham, and this release closes them: you can
now publish a subset of your binder as a first-class edition, preview a
translated edition without minting throwaway versions, and let Claude read
preview pages directly instead of shelling out to PDF tools.

## What you'll notice

- **Publish part of a project.** Each piece now has an `include` switch in
  the publish config. Drafts for a future volume can sit in the same binder
  without blocking today's book — excluded pieces don't compile, don't
  appear in the contents, and don't gate a translated edition. Republishing
  an old version faithfully reproduces whatever subset it was built from.
- **Try an edition before you commit.** `preview_compile` now takes a
  language (with the same loud coverage gate as a real compile), and
  `compile` has a `dry_run` that answers "would this edition build?"
  without creating output, a Publication record, or a version bump. No more
  junk versions in your history just to check the Spanish templates.
- **Claude can see previews.** A new `read_preview_page` tool rasterizes
  preview pages the same way it already reads published pages — the
  edit → compile → look loop no longer needs poppler or any external
  tooling.
- **Screenplay title pages can be styled.** The fountain title block is
  emitted through a `\screenplaytitleblock` hook a per-piece style file can
  redefine — the last hardcoded piece of screenplay typography.
- **Four LaTeX defects from real use are fixed** — chapter titles missing
  from the table of contents with custom ToC styles, scene-break centering
  leaking into following paragraphs, hard line breaks swallowing lines that
  start with `[`, and style-file scoping is now a documented, probe-enforced
  contract.
- **Safer updates to your Claude Code skill.** If you hand-edited the
  installed Maugham skill, the setup sheet now notices and asks before
  replacing it instead of silently overwriting. (First update after this
  release shows the confirmation once — that's the new guard noticing a
  pre-marker install.)

## Under the hood

- `read_preview_page` brings the MCP catalog to 52 tools; `translation_status`
  rows now carry a `verbatim` count and `write_translation` warns when a
  translation equals its source without being marked verbatim.
- Each project's `EMISSION.md` contract doc now refreshes on every compile
  and preview, stamped with the generating app version — it can no longer
  drift from the installed pipeline.
- Research moves got durability hardening: a failed batch move now rolls
  back cleanly instead of stranding files, notes dedupe jointly with their
  assets folders, and a cosmetic image-reference rewrite can no longer
  abort a committed move.
- The defect that restyled pieces across style-file boundaries could not be
  reproduced in a faithful six-piece probe; the probe is now permanent and
  the safe hook-scoping pattern is a hard rule in the emission contract.
