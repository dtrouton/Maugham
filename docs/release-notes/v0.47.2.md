# Maugham 0.47.2

_Released 2026-11-17_

One fix to the updater. Mac only.

## Fixes

- **An update can no longer be installed and then undone.** If Maugham started its installer twice for the same update, the two ran together: the new version was put in place and the old one put straight back, with no message, or a good download was reported as refused and deleted. Only one installer now runs per update.

## Known issues

- **Installing this update from 0.46.0 or 0.47.0 can still stick,** because that fault is in the version you are leaving: after **Restart & Update**, Maugham stays on screen but nothing opens or saves. Close every project window before clicking **Restart & Update**. If it is already stuck, force-quit it (⌥⌘Esc → Maugham → Force Quit); if the old version comes back, download the new one from the Releases page and drag it into Applications. Text typed after clicking **Restart & Update** was not saved.
