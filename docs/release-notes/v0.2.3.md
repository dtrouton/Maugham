# Maugham 0.2.3

_Released 2026-05-23_

App icon, plus a visually-distinct dev variant.

## What's new

- **Maugham has an app icon.** Serif M (Iowan Old Style Black, matching the in-app prose face) on a warm paper-cream squircle. A paragraph mark is carved into the M's right vertical via alpha-subtraction — reads as deliberate negative space rather than an overlay. First read: M. Second read: the writer notices ¶. Reflects the codebase's actual architecture (paragraph-keyed op log) without announcing it.
- **Dev builds get their own icon.** Compound mark: the ¶'s stem aligns with the M's left vertical so they share a stroke, with the ¶ in terracotta orange. Instantly distinguishable from the stable icon at any size — useful when both apps live in the dock together.

## Known issues

- First open of each downloaded `.dmg` still requires right-click → Open in Privacy & Security. Will go away when we flip to signed + notarized builds.
