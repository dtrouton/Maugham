# Maugham 0.7.0

_Released 2026-06-07_

A small writing feature and a meaningful Find & Replace fix, on top of a large
under-the-hood cleanup.

## What's new
- **Combined and nested emphasis.** You can now write `***bold italic***` for text
  that's both at once, and nest emphasis like `*a phrase with **bold** inside*` —
  both render correctly as you type. Previously the prose editor treated bold and
  italic as mutually exclusive, so combined and nested cases didn't show.

## Fixes
- **Find & Replace now sticks.** Replacing text across documents (⌘⌥F → Replace /
  Replace All) is now recorded the same way your own edits are. A replacement can
  no longer be quietly undone by autosave or a re-render — it survives quit and
  relaunch. Replacing inside a document that's currently open updates it in place,
  without disturbing your cursor.

## Notes
- This release also folds in a large internal cleanup — dead code removed,
  duplicated logic unified into single shared implementations, and the largest
  source files split for maintainability. There is no change to your projects or
  anything on disk.
- The release pipeline itself was hardened as a supply-chain precaution: build
  dependencies are now pinned to exact, verified versions. Signing, notarization,
  and in-place updates are unchanged from 0.6.x.
