# Maugham 0.3.1

_Released 2026-05-25_

Stabilization pass after v0.3.0 smoke. Fixes a cluster of lifecycle races and an updater cache issue.

## Fixes

- **Rename now reliably updates the file on disk.** When the renamed doc was open, its autosave would re-create the file at the old name a moment after the rename — leaving a phantom file behind. Maugham now closes the open Document (flushing any pending typing) before moving the file, so disk and binder stay in agreement.
- **Delete no longer leaves orphan files in `manuscript/`.** Same race as rename — autosave re-created the file at the original path after the trash move. Same fix: close-before-FS-surgery.
- **Rename mode reliably focuses the TextField on new docs.** Creating a new doc set both selection and rename mode in the same tick; List's selection focus claim sometimes won, leaving you with a selected-but-not-editing row. The TextField now claims focus with a brief deferral that lets the selection pass settle first, and listens for `renamingItemId` changes for the context-menu Rename path.
- **Check for Updates fetches fresh from GitHub.** `URLRequest` used the default cache policy, so the GitHub Releases API response stuck in URLSession's URLCache for the lifetime of the app. Mid-session checks always reported "up to date" even after CI had published a newer release. Now the request bypasses both URLCache and any intermediate CDN cache.

## Housekeeping

- Removed the "Edit history is now tracked" popup that ran on first project open. Dead code from when op-log was a new architectural addition; onboarding tours land in a future milestone, not via that one-shot sheet.
- Removed `UIState.scrollLine` — persisted to `.maugham/ui-state.json` and exercised by tests but never read by any production code path. Cursor restore actually flows through `Document.cursorLocation` (per-doc state), so the UIState field was dead. JSONDecoder ignores unknown keys, so old `ui-state.json` files load cleanly.

## Known issues

- First open of each downloaded `.dmg` still requires right-click → Open in Privacy & Security. Will go away when we flip to signed + notarized builds.
