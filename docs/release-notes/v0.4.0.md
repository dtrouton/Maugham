# Maugham 0.4.0

_Released 2026-05-29_

Publishing. Maugham can now turn your manuscript into something you can share.

## What's new

- **Publish to PDF and EPUB.** Compile a project — novel, story collection, mixed collection, or screenplay — into a sharable PDF (typeset with a bundled LaTeX engine) or EPUB. Outputs land in a new **Exports** section in the binder; click to open, right-click to reveal in Finder or delete.
- **Claude co-authors your typography.** Rather than a fixed house style, each project gets its own LaTeX template that you and Claude (via Claude Desktop) tune to taste — drop caps, scene-break ornaments, fonts, page geometry. Ask Claude to "set up publishing for this project," then iterate: Claude proposes typography, compiles, and looks at the rendered page with you.
- **Per-piece typography.** Individual pieces can carry their own styling (a numbered chapter heading here, a special title page there) without disturbing the rest of the collection.
- **Custom fonts.** Drop a font into the project and set your body face; Maugham's engine picks it up.
- **Richer Claude Desktop surface.** The MCP tool surface grows to 40 tools covering compile, configuration, per-piece styling, and reading the generated build artifacts. A new `list_maugham_tools` gives Claude an authoritative list of what's available and which build it's connected to.

## Fixes

- Tools that take a piece id now fail loudly on an unknown id (instead of silently doing nothing), so misdirected publishing commands surface immediately.
- The Exports list scrolls when it gets long and sorts most-recent first.

## Known issues

- **First publish is slow.** The first PDF compile downloads the LaTeX package set (~150 MB) from the open-source Tectonic CDN; subsequent compiles work offline. Needs a network connection the first time.
- **EPUB is "blind" for Claude.** Claude can read the EPUB's generated source but can't see how a reader renders it — EPUB styling is iterated by you describing what you see, where PDF is fully visual.
- Builds remain unsigned: first launch needs **right-click → Open**.
