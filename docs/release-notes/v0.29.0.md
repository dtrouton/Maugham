# Maugham 0.29.0

_Released 2026-08-16_

Review earns its keep. Since 0.28 the Review persona has grown the
structure professional editing actually uses: named passes at one
altitude of attention each, a board that shows where every piece stands,
a working queue with triage and *stet*, and a compiler that remembers
rounds — what got resolved, what persists, and whether the draft has
drifted from what you said you were writing.

## What you'll notice

- **Named passes.** Every project starts with Structural, Line, Copyedit,
  Proof — rename, add, delete, or reorder them per project in Project
  Settings. Order advises, never blocks: every pass is always available
  on every piece, and working a later pass while an earlier one is open
  gets you a quiet note, not a dialog.
- **The pass ladder replaces the status picker.** A piece's status
  (draft / revising / final) is now *derived* from the passes you've
  actually ruled on — in progress, done, or skipped — set in the
  Inspector's ladder or on the board. Your old status strings still show
  until you touch a pass; nothing is rewritten.
- **Review's project row is the board.** Select the project in Review and
  the centre fills with pieces × passes: a chip per (piece, pass), a
  trailing open-notes count per row. Click a chip to open that piece with
  that pass active and its queue filtered to it; right-click to set
  in progress / done / skip.
- **The queue works in batches.** The annotations pane sorts triaged-*do*
  first, filters by kind, author, triage, and pass, and takes multiselect
  bulk actions — accept-all, stet-all, triage-all — one ⌘Z per batch.
  **Stet** joins accept / reject / archive: "it stands, deliberately."
  A scope toggle widens the queue from this piece to the whole project,
  grouped by piece.
- **Rounds.** A ⌘R while a pass is active is a numbered round, and the
  next report leads with what changed: *"Since round 2: 3 resolved ·
  1 persisting · 2 new."* The comparison is computed from your own
  sidecar, not the model's memory.
- **Fresh Eyes (⌘⇧R).** When familiarity blinds, end the warm session
  and have the piece read whole, cold — briefed on your intent and
  rulings but deliberately not on prior findings. Tagged in the report
  header so you always know which kind of read you're looking at.
- **Drift, judged.** Each round also answers one more question: has the
  draft drifted from the declared intent? A *drifted* verdict puts a
  quiet "intent may trail the draft" mark on the intent strip until a
  later run clears it — or you edit the statement. No timers, no nags.
- **The assistant column studies in Review too.** Click a pinned
  reference while adjudicating and it opens beside the prose, exactly as
  in Author. Plan and Publish keep the shelf read-only.
- **Claude sees the same truth.** `get_outline` now reports each piece's
  derived status, per-pass states, and the project's pass ladder;
  `list_annotations` reports triage marks and pass stamps. Claude still
  can't set any of them — triage, stet, and pass states are writer verbs.

## Fixes

- A compiler check whose session died mid-run no longer collapses the
  report to a sentence with no body — the run fails once, visibly, and
  the next ⌘R starts fresh (#36).
- The queue's toolbar no longer crowds its pane at narrow widths — the
  controls are icons with their names in tooltips and menus.

## Known issues

- Round memory is per document and six checks deep — a pass revisited
  after six intervening checks starts its numbering over.
- The phone reads everything this release writes but has no pass or
  triage surface of its own yet.
