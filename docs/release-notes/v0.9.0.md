# Maugham 0.9.0

_Released 2026-06-08_

Re-run transcription on any voice capture — handy when a recording came back
blank or when you've switched to a more capable transcription model — and see
*why* a transcription failed instead of being left with an empty box.

## What's new

- **Transcribe again.** Right-click any voice capture in the Inbox and choose
  **Transcribe** (for one that never produced a transcript) or **Transcribe Again**
  (to redo one). It re-runs on the model currently selected in **Settings → Voice**,
  so after switching to a larger, more accurate model you can redo earlier captures
  and get the better result. Captures you've hand-edited are left alone — your text
  is never overwritten.
- **See why a transcription failed.** When a capture can't be transcribed, its Inbox
  row now reads **"Failed · …"** with the reason, and the reason also appears above
  the text when you open **Edit Transcript…** — so a failure is visible and
  actionable instead of silent.

## Fixes

- **A blank transcript no longer erases your draft.** When the transcriber returned
  nothing for a clip (a silent or unclear recording), Maugham was treating that as a
  successful empty transcription and wiping the draft the phone had captured. An empty
  result is now treated as a failure that **keeps your existing draft** and explains
  what happened.
- **Captures that never got transcribed are no longer stuck.** A voice memo that
  synced from the phone but was never picked up for transcription now offers a manual
  **Transcribe** action, so it always has a way forward.

## Notes

- Local transcription is macOS + Apple-Silicon only (it uses on-device WhisperKit);
  the iPhone companion is unchanged. The transcription model is chosen in
  **Settings → Voice** and downloads on first use.
- Very long recordings (beyond about five minutes) can still transcribe poorly —
  Maugham doesn't yet split long audio, so a larger model won't necessarily help
  there. Signing, notarization, in-place updates, and backups are unchanged from
  0.6.x–0.8.x.
