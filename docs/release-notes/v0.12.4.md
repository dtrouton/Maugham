# Maugham 0.12.4

_Released 2026-06-29_

A correctness release: everything that reads your manuscript — publishing,
search, and the Claude integration — now works from the same single source of
truth, so it always reflects your latest edits, even in edge cases (right after
typing, or after changes synced from another Mac).

## Fixes

- **Publishing always reflects your latest text.** Exported PDFs and EPUBs are
  now built from Maugham's authoritative record of your manuscript rather than
  the rendered file on disk, which could occasionally lag a beat behind. Your
  published output now always matches what you wrote.

- **Claude can comment reliably.** When Claude reviewed a document that wasn't
  open in the editor, it could read a paragraph and then be told that same
  paragraph "doesn't exist" when it tried to comment on it. Both sides now read
  from the same source, so comments land where they should.

- **Search and link lookups reflect your current text.** Cross-document search,
  `[[wiki-link]]` graphs, and scene/reference lookups now read your manuscript's
  current state rather than a file that might be slightly stale.

## Notes

- Nothing changes about how you write or save, and your manuscript files are
  untouched — this is purely about everything *else* reading the same
  up-to-date source. The iPhone companion app is unchanged (it ships
  separately).
