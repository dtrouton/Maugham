# Maugham 0.8.0

_Released 2026-06-07_

Automatic, verified backups — your projects are now copied to folders you choose,
checked for corruption before each copy, and recoverable without ever touching
your live work.

## What's new

- **Automatic backups.** In **Settings → Backups**, add one or more folders to back
  up to — a local folder, an external drive, or a Dropbox/OneDrive/Drive-synced
  folder (anything that looks like a folder works; Maugham just writes files, the
  syncing is your cloud app's job). From then on, every time you save (⌘S) Maugham
  writes a complete, verified copy of the project to each destination. Local folders
  use copy-on-write, so keeping many copies is nearly free; you set how many
  generations to keep per destination.
- **Corruption never gets backed up.** Before each backup, Maugham checks the
  project's edit history for damage and **refuses to back up a corrupt project** —
  so a problem can't silently propagate into your backups. If that happens, a
  **"Backups paused"** banner appears across the top of that project's window.
- **Restore, safely.** **File → Restore from Backup…** (or the banner's **Restore…**
  button) lists your backup generations, marks each as verified or damaged, and
  restores a chosen one **beside** your project — into a new folder you pick. Your
  live project is never overwritten. Maugham can also skip past a damaged backup to
  the newest intact one.
- **Share one backup folder across projects.** Each project's backups are kept in
  their own subfolder, so you can point several projects at the same backup
  destination without them mixing.

## Fixes

- **Front-window actions stay in the front window.** With two or more projects open,
  a number of commands were quietly acting on *every* open project at once —
  pressing ⌘S checkpointed and backed up the background project too, ⌘⌥Z restored a
  deleted item in all of them, "Add Research File" imported into all of them, and
  adding a piece to one collection added an untitled piece to the others. These now
  affect only the project you're working in.
- A project's "Backups paused" warning no longer shows on *other* open projects'
  windows — each project's backup status is its own.

## Notes

- Backups, integrity checks, and restore are macOS-only for now; the iPhone
  companion is unchanged.
- Encryption of backups is left to your destination (use an encrypted disk or a
  cloud provider's at-rest encryption). Signing, notarization, and in-place updates
  are unchanged from 0.6.x / 0.7.x.
