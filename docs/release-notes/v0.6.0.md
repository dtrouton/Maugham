# Maugham 0.6.0

_Released 2026-06-03_

Maugham is now **signed, notarized, and updates itself in place.** No more
right-click → Open on first launch, and no more dragging a disk image to update —
when a new version is ready, Maugham installs it for you.

## What's new
- **Signed & notarized builds.** Maugham is now signed with a Developer ID
  certificate and notarized by Apple. The first launch after downloading is
  Gatekeeper-clean — the "unidentified developer" right-click → Open dance is gone.
- **In-place automatic updates.** When a new version is available, Maugham
  downloads it quietly in the background and shows a small "ready to install"
  notice. Click **Restart & Update** and it swaps itself out and relaunches — or
  just **Dismiss** it and the update applies the next time you quit. No disk
  image, no dragging to Applications.
- **Verified before installed.** Every downloaded update is checked — code
  signature, your developer Team ID, and Apple's notarization — before it's ever
  swapped in. A tampered or unexpected build is refused, not installed.

## Fixes
- If Maugham can't write to its own location (e.g. installed somewhere read-only),
  it falls back to the previous behavior — revealing the download in Finder — so
  an update is never worse than before.

## Notes
- This is the first release that updates itself in place. Updating *to* 0.6.0 from
  an earlier version still uses the old reveal-in-Finder step (that's the last time
  you'll do it manually); every update *after* 0.6.0 installs itself.
