# Maugham 0.23.0

_Released 2026-07-18_

Maugham now teaches Claude how to work on your writing — properly, and in
a way that keeps up with the app. Instead of re-explaining your
transcription workflow or what a good editing pass looks like every
session, Maugham carries that know-how itself and hands it to Claude the
moment it's needed.

## What you'll notice

- **Claude learns Maugham's workflows on its own.** Two built-in skills
  ship with the app: *transcribing notebooks* (faithful, line-complete
  transcription of handwritten pages into research notes — with strict
  honesty rules about what it can't read) and *editing pass* (feedback
  the way a professional editor gives it: the right kind of pass for a
  draft's status, patterns named once instead of forty corrections, your
  craft intent always in charge, and praise for what's working). Claude
  fetches them through the existing `get_help` tool, so they're always
  current with your installed version.
- **One-click Claude Code setup.** The Claude setup sheet gains a Claude
  Code section: a copyable connect command, and an "Install Claude Code
  Skill" button that adds a small router so Claude automatically loads
  Maugham's workflows whenever you're working with the app. If a Maugham
  update improves the skills, the sheet tells you.
- **The editing skill reads your document status.** Mark a piece Draft,
  Revising, or Final in the Inspector and an editing pass calibrates to
  it — structural feedback for drafts, line editing for revisions,
  continuity and correctness for finals.

## Ahead of the standard

Skills over MCP is an emerging open standard (the MCP Skills Extension,
currently in draft). Maugham already speaks it: any client that adopts
the extension will discover and load Maugham's skills with no app update
needed. Until then, the `get_help` route and the installed router do the
same job today.

## Under the hood

- New MCP protocol surface (`skills/list`, `skills/get`, `skill://`
  resources with content digests) — protocol methods, not tools; the
  tool count is unchanged at 48.
- Skill content is integrity-checked (per-file SHA-256) and served from
  a single bundled source.

## Compatibility

- No manuscript, op-log, or schema changes. Phone pairing unchanged —
  MaughamPhone 0.7.0 continues to work; no phone update required.
