# Maugham 0.14.0

_Released 2026-07-06_

A writing-grammar release. Maugham's Markdown and Fountain support was audited
line-by-line against the CommonMark and Fountain specs, every gap was decided
on purpose, and the ones worth having are now in — plus a class of publishing
bugs that could put words you'd deleted into your compiled PDF is gone.

## What's new

- **Strikethrough in prose.** Type `~~like this~~` and it renders struck
  through everywhere prose lives — the editor, the phone Read tab, published
  PDF and EPUB. Screenplays keep `~` for lyrics, as the Fountain spec says.
- **Italics can span a stanza.** An emphasis span may now open on one line and
  close on another within the same paragraph — so a multi-line quoted verse or
  letter can be italicized with a single pair of asterisks. (It still never
  crosses a blank line.)
- **Backslash escapes.** `\*not italic\*` now means what it says, in the
  editor and in every published format. Escape `*`, `~`, `_`, backticks, or a
  backslash itself.
- **Scene numbers.** End a slugline with `#4A#` and Maugham carries it as
  metadata: faded in the editor, right-aligned on the slugline in published
  PDF/EPUB.
- **Dot-less sluglines.** `INT ROOM - DAY`, `I/E CAR - NIGHT`, and the other
  spec-valid stem forms now classify as scene headings — the trailing dot is
  no longer required.
- **Dual dialogue publishes side-by-side.** A `^`-marked cue now renders as
  true two-column dual dialogue in PDF and EPUB.
- **Lists and more in published prose.** Bullet and numbered lists render as
  real lists in PDF/EPUB; a ``` code fence passes through verbatim instead of
  being mis-read as emphasis; `***` and `###` work as scene breaks in the
  editor just as they already did in publish.
- **Two-space held line in dialogue.** The Fountain idiom — a line of two
  spaces inside a speech — now keeps the dialogue block open all the way
  through to published output.
- **The Help window renders its own docs properly.** The keyboard-shortcut
  reference now shows as a real table, and numbered steps stay numbered.

## Fixes

- **Deleted material no longer leaks into compiled screenplays.** Boneyard
  (`/* … */`), notes (`[[ … ]]`), synopses, and section markers were being
  published verbatim into PDF/EPUB — including text you had deliberately cut.
  Screenplay publishing now runs through the same parser as the editor, so
  what you see is what compiles.
- **`***bold italic***` publishes correctly in prose** (it previously came out
  mangled as `*x` plus a stray asterisk).
- **Underscores in prose are literal everywhere.** `snake_case_word` no longer
  italicizes in published output — matching what the editor shows.
- **Research previews reflow paragraphs** instead of stacking every
  hard-wrapped line as its own fragment.
- **`![image](…)` syntax in a manuscript no longer half-styles as a link.**
- The in-app Markdown and Fountain syntax guides have been rewritten to match
  actual behavior exactly, including a documented list of what's deliberately
  not supported.

## Known issues

- Scene numbers don't display on the phone Read tab (the reading view shows
  the clean slugline; the number still appears in published output).
- EPUB dual-dialogue columns use the starter stylesheet; readers that ignore
  publisher CSS may stack the columns.
