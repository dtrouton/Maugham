# Maugham 0.33.0

_Released 2026-08-28_

Imprints and bilingual editions: one project can now ship its book *and* a
special edition — a different look, a different set of pieces, its own
version counter — and either can hold two complete languages in one
volume, each reading as a work in its own right. Three plans, one
milestone, shipped whole.

## What's new

- **Imprints.** An imprint is a named publishing configuration inside a
  project — its own template, its own rendered set of pieces (an
  *allowlist*: naming a piece is what includes it), its own metadata,
  cover, filename and `next_version` — declared under `imprints` in
  `.maugham/publish/config.json` and chosen at compile time. A collection
  can ship its whole book and a one-piece special edition with a different
  typography, without forking the project or the manuscript. Resolution
  happens once, at the door: pass `imprint` to `compile` or
  `preview_compile` and everything downstream sees an ordinary,
  already-resolved config. Validated at save and at compile — name
  alphabet, template present and distinct from the book's, allowlist
  non-empty and real. A publication is now keyed on
  `(imprint, version, language, format)`; `list_publications` and
  `read_publication_page` take `imprint` too, with `"book"` selecting what
  no imprint compiled. The `{imprint}` filename token joins `{language}`,
  and is inserted before the extension automatically if your template
  doesn't mention it, so an imprint compile never overwrites the book's
  file. Republishing an imprint reproduces the pieces it shipped with, not
  the pieces the project has since gained.
- **Bilingual editions.** Pass `languages: ["en", "sr"]` and you get one
  document holding a complete body per language, **sequential and
  unrotated** — the source runs start to finish, then the translation.
  `"source"` (or the book's own tag) names the untranslated body; a set
  including it is a source compile that mints a version, a set without it
  is an edition of an existing one. The identity carries every language
  joined — `en+sr` — as its own publication beside the single-language
  editions of the same version. The translation-coverage gate runs once
  per tongue and the refusal lists every blocked tongue's gaps together,
  each prefixed `[tag]`; `allow_stale` applies to all of them. Design
  rounds now sample the *edition's* text, and the design gate says when
  the book's own words stood in for an untranslated piece.
- **`MaughamBody` is the seam between the halves.** `build/body.tex` is a
  thin wrapper: a guard defining a default `MaughamBody` environment if
  your template hasn't, then one `\begin{MaughamBody}{<tag>}…` block per
  rendered language. The default is a `\clearpage` between halves and
  nothing else — a template whose frontmatter already ends a page
  (the starter's, Playlist's) paginates exactly as before, measured.
  Redefine it to give each half its own title page:
  `\renewenvironment{MaughamBody}[1]{\clearpage\input{frontmatter-#1}}{}`;
  or `\renewenvironment{MaughamBody}[1]{}{}` to opt out of the page break
  entirely.
- **Every paragraph is anchored, and scene headings link across the
  halves.** Every compiled artifact carries an invisible
  `\hypertarget{p-<tag>-<¶id>}{}` (PDF) or `id="p-<tag>-<¶id>"` (EPUB) per
  paragraph — the first artifact-side id a template can rely on. In a
  multi-language compile, each slugline links to the same scene in every
  other body: tap a slugline in the Serbian half and land on it in the
  English. In the EPUB the same tap crosses section files. Two
  `\providecommand` fallbacks ride in every body's own prologue, so a
  preamble that has never heard of either still compiles — and the
  cross-link fallback links wherever `hyperref` is loaded, so a project
  initialised before this release links too.
- **Compile from the desk.** The Publish desk (⌘⌥K) gained an **Imprint**
  picker in its header — Book, then one row per declared imprint,
  remembered per project — and **Compile…**, a sheet with a format, a
  checkbox per language (the book's own checked by default) and
  `allow_stale`, running the same orchestrator, mint gate and coverage
  gate the MCP `compile` tool runs. It is the desk's first action that
  needs no Claude session. The desk's status line follows the run and
  Cancel stops exactly that compile and nothing else. A run refused by the
  gate is drawn as a refusal, in Maugham's words, not as a failure.
- **Every surface names a book the same way.** The Publish persona's
  compiled-book preview, its picker, the desk's status line and the
  Exports footer all read one shared composition —
  `v1.0 · special-glb · EN+SR · date` — so none of them can disagree about
  what a book is called, and a bilingual volume is never labelled by one
  of its halves.

## Under the hood

- No manifest schema change — Mac-only release; MaughamPhone 0.10.0 stays
  current.
- EPUB sections now carry `xml:lang`, one `<dc:language>` per body, and a
  nav grouped per body — a byte-level change for every EPUB compile, not
  only bilingual ones.
- `EMISSION.md` gained the anchor form, `\MaughamCrossLink`, the
  `MaughamBody` environment and "Imprint templates are not style files";
  the byte gate moved with it.
- Same-edition compiles are refused fast by the four-part mint key rather
  than raced; the desk cancels only the job it registered
  (`CompileOrchestrator.compile(onJobRegistered:)`).
- `PublishToolchain` is the one home for the Maugham and tectonic version
  strings the desk and the tools report.

## Known issues

- Only sluglines cross-link between bodies; every other paragraph anchors
  but links nowhere yet.
- The slugline cross-link wraps `\scene` (which contains a `\par`) inside
  `\hyperlink`; this is verified under tectonic/XeTeX, which the bundled
  engine is. A template compiled by hand under pdfTeX may object.
- A bilingual EPUB carries one stylesheet (the unsuffixed one), and the
  document-level title page and PDF metadata are always the first listed
  body's.
- A design round on an edition that has a translator but no translation
  records refuses loudly rather than silently sampling the source book
  under the edition's label.
