# Maugham 0.21.1

_Released 2026-07-13_

A one-fix release: **Check for Updates works again.**

## Fixes

- **"Check for Updates" no longer errors with "Couldn't parse version from
  release."** When the iPhone companion app happened to be published to
  GitHub a few minutes *after* the matching Mac release — as it was for
  0.21.0 — the Mac updater mistook the phone release for the Mac one and
  couldn't read its version. Maugham now always picks the newest *Mac*
  release, whatever order the two apps were published in, so updating is
  reliable from here on.

## Compatibility

- Pairs with **MaughamPhone 0.7.0**. No manuscript, op-log, or schema
  format change — fully compatible with 0.20.0 and 0.21.0 in both
  directions.
