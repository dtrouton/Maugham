# Maugham 0.46.0

_Released 2026-11-16_

A safer updater, and fixes that stop suggestions, Research tables and quitting from losing work without saying so. Mac only; MaughamPhone 0.16.0 is still current.

## What's new

- **Updates no longer need Python.** Maugham now replaces itself with its own small tool. On a Mac without Xcode's Command Line Tools, the old updater failed on every attempt. **If that is your Mac, this one update won't install by itself: download 0.46.0 from the Releases page and drag it into Applications. Later updates install themselves.**
- **An update is checked for which app and version it is.** Before installing, Maugham confirms the download is Maugham itself, at the version it expected, as well as signed by Maugham's developer and approved by Apple.
- **Maugham replaces itself in one step or not at all.** On a disk that can't do that (exFAT, some network drives), **Restart & Update** shows the new version in Finder for you to drag into place.
- **A restored Check for Updates window waits for you.** If the window comes back by itself when Maugham reopens, it doesn't check until you click **Check Now**.

## Fixes

- **Suggestions**
  - Accepting a suggestion whose change is already in the text marks it Accepted and leaves the text alone. The change is not applied a second time, and ⌘Z reopens the suggestion without touching the text.
  - The same holds for a table cell that already holds the suggested value.
  - Undoing a rewind that had archived an accepted suggestion brings it back as Accepted, not Open.
- **Reverting to a checkpoint**
  - A revert now answers the suggestions on a document's tables, only where it rewrites the suggested cell. The sheet counts them before you press **Revert** and reports them afterwards.
- **Research tables**
  - Edits are no longer dropped when a table can't be saved. At ⌘S, on leaving the grid, and on closing the project or quitting, they are kept as a copy in the project's `.maugham/conflicts` folder, and the notice names the file.
  - If only the table's previous version can't be kept, your edits are saved anyway and the notice says so.
- **Quitting**
  - ⌘Q waits, up to ten seconds, for open projects to finish saving before Maugham exits.
- **Updates**
  - A background check no longer disturbs an update that is ready to install or installing.

## Known issues

- After a quit there is no window to show a "couldn't save" notice for a Research table. Look in the project's `.maugham/conflicts` folder for a file ending `-unsaved-` and a date.
- Restoring a version of a note or card from before it was renamed brings back links to its old picture folder, so those pictures don't show.
