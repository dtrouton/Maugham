# Maugham 0.3.3

_Released 2026-05-26_

Targeted fix for the auto-update path.

## Fixes

- **"Check for Updates…" now actually re-checks on every open.** v0.3.1 fixed URLCache staleness on the GitHub fetch, but the sheet was only invoking the fetch when state was `.idle`. After the first background poll on app launch, state becomes `.upToDate(…)` and stays there — so subsequent manual clicks rendered the cached "up to date" message without ever re-fetching. The URLCache-bypass fix was correct but never exercised by the manual path. Fix: re-check on every sheet open unless an active download/install is in progress.

## Known issues

- First open of each downloaded `.dmg` still requires right-click → Open in Privacy & Security. Will go away when we flip to signed + notarized builds.
