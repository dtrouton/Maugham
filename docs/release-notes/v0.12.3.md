# Maugham 0.12.3

_Released 2026-06-28_

A bug-fix release focused on the editor and reviewing — all caught in real
writing sessions.

## Fixes

- **Screenplay styling keeps up as you type.** In screenplay mode the element
  styling (scene headings, character cues, dialogue, action) had started lagging
  a beat behind your typing. It's live again — formatting applies as you write.
  (Prose still settles its emphasis styling a moment after you stop, the way it
  has since 0.12.2 — that calm behaviour was only ever meant for prose.)

- **Your own document is editable the moment it opens.** A document could open
  read-only and only become editable after you clicked away to another piece in
  the binder and back. It's editable right away now.

- **Accepting a suggestion changes only what was suggested.** When a suggested
  change covered just a few words, accepting it replaced the *entire paragraph*
  with those few words. Now it replaces only the words the suggestion covered,
  leaving the rest of the paragraph intact.

- **The suggestion preview shows the actual change.** In the Annotations pane a
  few-word suggestion was shown as "[the whole paragraph] → [the new words]",
  which read as though the whole paragraph would be replaced. It now shows just
  the part that changes — e.g. "very angry → furious".

## Notes

- No changes to your manuscripts, sync, or publishing. The iPhone companion app
  is unchanged in this release (phone updates ship separately via TestFlight).
