# MaughamPhone 0.7.0

_Released 2026-07-12_

A maintenance release that rides along with Maugham 0.21.0's hardening
pass. Nothing new to see on the phone — the shared foundation both apps
stand on got firmer, and the phone inherits it.

## Under the hood

- The shared MaughamCore substrate — the parsing, sync, and palette code
  the phone runs identically to the Mac — picked up the correctness and
  robustness fixes from Maugham 0.21.0's review. Palette rendering, inbox
  capture layout, and document-id handling all consume the same hardened,
  now-single-source implementations.

## Compatibility

- Pairs with **Maugham 0.21.0**. No schema or format change; fully
  compatible with 0.20.0 in both directions.
