# MaughamPhone 0.0.3

_Released 2026-05-31_

## What's new
- Third pipeline dry run — verifies the screenplay rendering fix (and an annotation
  display fix) on a real TestFlight build. Not a feature release; delete after verifying.

## Fixes
- Screenplays now render fully: the title page shows, and manuscript paragraph
  markers (`<!-- ¶id -->`) no longer leak into the body. (Root cause: the Fountain
  reader parsed raw text instead of stripping anchors first.)
- Annotation detail "Current/Suggested/Paragraph" blocks no longer show inline task
  anchors (`<!--t-…-->`) when the annotated paragraph contains a `[[todo]]`.

- Throwaway build. The first real release is `phone-v0.1.0`.
