# MaughamPhone 0.5.0

_Released 2026-07-10_

Decisions made on the phone are no longer final: resolved annotations gain
a Reopen button, pairing with Maugham 0.18.0's everything-is-undoable
release on the Mac.

## What's new

- **Reopen a resolved note.** Rejected or archived a note and changed your
  mind? Open it from the Resolved list and tap **Reopen** — it returns to
  Open on every device, same as ⌘Z on the Mac.
- **Reopen & Revert an accepted suggestion.** For a suggestion you
  accepted, **Reopen & Revert** restores the manuscript text to what it
  was before the accept *and* reopens the note — identical to the Mac's
  Revert button. If the paragraph has changed since you accepted (or no
  longer exists), the phone asks first instead of touching it.

## Compatibility

- **Update together with Maugham 0.18.0 on the Mac.** Projects *created*
  by the new versions use a newer project format that older app versions
  refuse to open. Existing projects are unaffected.
