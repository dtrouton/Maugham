# MaughamPhone 0.4.0

_Released 2026-07-09_

Keeps the phone in step with Maugham 0.17.0's suggestion changes: reverted
suggestions read correctly, and accepting a span suggestion on the phone
applies it as safely as the Mac does.

## Improved

- **Reverted suggestions show correctly.** When a suggestion accepted on
  the Mac is later undone (⌘Z, the new Revert button, or a History rewind),
  the phone's Annotations tab shows it back in Open with the manuscript
  text restored — instead of a stale "accepted" state.
- **Safer accepts.** Accepting a suggestion that was authored as a
  full-paragraph rewrite but anchored to a quoted phrase now applies the
  rewrite cleanly instead of splicing a paragraph into itself — the same
  fix as the Mac, from the same shared engine.

## Compatibility

- **Update together with Maugham 0.17.0 on the Mac.** Projects *created* by
  the new versions use a newer project format that older app versions
  refuse to open. Existing projects are unaffected.
