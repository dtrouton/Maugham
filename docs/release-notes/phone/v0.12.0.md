# MaughamPhone 0.12.0

_Released 2026-09-09_

The pairing release for Mac 0.38.0, carrying the signed op log's
performance step. The phone reads a project's history through the same
shared parser and chain the Mac does, so it gets the same gain: a long
history opens in a fraction of the time it took in 0.11.0.

## What's new

- **A cold open is ten times faster.** Parsing the dates in a history was
  most of what a cold open cost; a hand parser for the two ISO 8601 shapes
  Maugham writes (the old formatter stays as the fallback for anything
  else) takes a fifty-thousand-line history from about six seconds to
  half a second on the Mac, and the phone runs the same code. The chain
  walk over a live tail reads its `prev` link by bytes.
- **The device state prunes.** The phone's `op-log-state.json`, kept by
  the same shared store, records each project's root and forgets projects
  whose root no longer exists.

## Fixes

- None phone-specific this release.

## Known issues

- The Mac's reader's-own-session work in 0.38.0 (liveness, session
  identity, run timing, inline pinned notes) is Mac-only; the phone has no
  compiler surface.
