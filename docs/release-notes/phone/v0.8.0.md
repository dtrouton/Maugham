# MaughamPhone 0.8.0

_Released 2026-08-09_

The pairing release for Mac 0.27.0. The Mac side grew personas, the
planning canvas, the intent compiler, and the one-tree binder; the phone's
job this release is to keep reading and annotating that world faithfully.

## What's new

- **Reads projects at manifest schema 5** — everything the Mac's new
  statements, publications, and register work stamp into a project opens
  cleanly on the phone.
- **Captures can land on the Mac's planning canvas** — an inbox entry
  sent to the canvas keeps its identity, so a capture you took on the
  phone is the same object when it becomes a scrap, and later a research
  note.
- **Trashed captures sweep at 30 days**, matching the Mac's trash
  discipline; nothing changes in how rows look on older phones.

## Fixes

- Op-log reads inherit the Mac's strict-read hardening: an unreadable
  file refuses loudly instead of showing an empty document.

## Known issues

- Statements (intent, visual language) are visible as ordinary project
  files but have no dedicated phone surface yet.
