# MaughamPhone 0.10.0

_Released 2026-08-21_

The pairing release for Mac 0.31.0. The Mac side grew the publishing
department — named translators, the book designer, and per-edition
briefs; the phone's job this release is to read that world faithfully.

## What's new

- **Reads projects at manifest schema 8** — production roles (your
  translators and designer) and edition-brief statements decode
  cleanly; nothing the Mac's publishing work writes makes a project
  unreadable on the phone.
- Translator-authored questions and whole-document queries render like
  any other annotation, signed by their author.
