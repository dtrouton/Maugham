# MaughamPhone 0.1.1

_Released 2026-05-31_

A bug-fix release: the Annotations tab now actually shows Claude's open notes.

## Fixed

- **Annotations no longer show up empty.** The Annotations tab read its document
  ids with a stricter rule than the rest of the system, so it matched none of the
  real op-log files and always reported "No open annotations" — even when the Mac
  showed them. It now recognizes documents the same way the Mac does, so open
  annotations appear across every project as intended.
- **Cold-launch sync now warms annotation/read data.** The first-launch background
  download used the same too-strict rule and was silently fetching nothing; it now
  pre-downloads each project's op logs, so the Annotations and Read tabs are ready
  faster and work better offline.

## Notes

- No data or settings change — reopen the Annotations tab (or pull to refresh) and
  your open notes will be there.
- Everything from 0.1.0 is unchanged: Capture, Read, annotation Accept/Reject/Archive,
  optional Face ID, shared iCloud-Drive folder.

## Known issues

- No live cross-device refresh yet — lists update on appear, pull-to-refresh, or
  after a phone-side action.
- Voice transcription refinement happens on the Mac (Apple Silicon); the phone keeps
  its on-device draft if the Mac can't improve it.
