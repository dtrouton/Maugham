# MaughamPhone 0.3.0

_Released 2026-07-07_

The Read tab now renders real structure. Manuscripts and chapters containing
lists, code blocks, tables, or quotes show them properly instead of raw
Markdown markers — using the same shared parser as the Mac.

## New

- **Lists render as lists.** Bulleted (`-`) and numbered items display as
  proper list rows instead of literal dashes and digits.
- **Code blocks show in monospace.** A ``` fenced block renders on a subtle
  background with its content verbatim — asterisks inside no longer italicize.
- **Tables render as grids.** Pipe tables display as real rows and columns
  with a bold header.
- **Quotes get quote styling.** `>` lines show with an accent bar and
  indentation, including nested quotes.
- **Scene dividers.** A `---` or `***` line renders as a centered ornament.

## Improved

- **Strikethrough** (`~~text~~`) and the other recent prose grammar additions
  (escapes, stanza-spanning emphasis) read correctly, matching the Mac editor
  and published output.
- Screenplay dialogue using the Fountain two-space "held line" idiom now
  reads as one continuous speech, matching the Mac and published PDF.

## Notes

- Plain paragraphs keep their line breaks exactly as before — nothing changes
  for ordinary prose.
- Scene numbers (`#4A#`) remain metadata on the phone: the reading view shows
  the clean slugline; the number appears in published output.
