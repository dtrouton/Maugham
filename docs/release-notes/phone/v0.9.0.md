# MaughamPhone 0.9.0

_Released 2026-08-16_

The pairing release for Mac 0.29.0. The Mac side grew review passes, the
board, triage and stet, and the compiler's rounds; the phone's job this
release is to read that world faithfully — manifest schema 7 opens
cleanly, and the new annotation states render honestly.

## What's new

- **Reads projects at manifest schema 7** — pass states, triage marks,
  stet resolutions, and pass stamps all decode cleanly; nothing the
  Mac's review work writes makes a project unreadable on the phone.
- **Stet-aware annotations** — a stetted note shows its settled state,
  and reopening one from the phone works exactly like reopening a
  rejected or archived one.
- Cross-project annotation aggregation now runs on the same shared
  MaughamCore derivation as the Mac — one implementation, two surfaces.

## Fixes

- None phone-specific this release.

## Known issues

- No pass or triage surface yet: the phone shows annotations and their
  states but review passes, the board, and triage marks are Mac-only
  for now.
