# MaughamPhone 0.11.0

_Released 2026-09-08_

The pairing release for Mac 0.37.0, the signed op log. The phone now writes
its history the way the Mac does.

## What's new

- **The phone has a key.** On first launch it mints one in the Secure
  Enclave and persists the key's opaque blob itself — no keychain item, no
  entitlement. Its identity is that key's fingerprint, so a reinstall is a
  new device to its own past, and its files are named for it.
- **Every line is chained and sealed.** Each annotation the phone writes
  (an accept, a reject, a reopen) and each capture it sends to the inbox is
  chained to the line before it and followed by a seal signed by the phone's
  key. The Mac reads them as another device's history until people and
  admission arrive in a later release.
- **The palette aim is gone.** A capture no longer carries a subject or a
  sense; where it lands is decided on the Mac at promotion, where the
  canvas now takes the inbox as a source. Rows already on disk keep what
  they carried.

## Fixes

- The phone's writers run off the main thread again; only the one-line
  append hops to it.

## Known issues

- The phone's own earlier files (named `phone:<uuid>`) are read by the Mac
  as unsigned history from now on and are never appended to again.
