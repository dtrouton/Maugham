# Maugham 0.2.1

_Released 2026-05-23_

Three follow-up fixes from the v0.2.0 first-install shakedown.

## Fixes

- **Dock and Cmd-Tab now distinguish Maugham from Maugham Dev.** v0.2.0 left both apps registered to macOS as "Maugham" because the SwiftUI display-name change didn't propagate to the bundle's `CFBundleDisplayName` / `CFBundleName`. Both now derive from the per-config build variant, so the macOS-level app identity matches the in-app brand.
- **"Check for Updates…" menu item now actually does something.** v0.2.0's implementation attached a `.sheet` to a `Button` inside a `Commands` body, which has no view-hierarchy host — clicks silently no-op'd. Replaced with a standalone "Check for Updates" Window scene opened via `@Environment(\.openWindow)`.
- **CI packaging switched to `ditto` from `cp -R`.** Speculative fix for a styling regression observed in v0.2.0's installed `.app` (grey panes, square buttons) that didn't reproduce on locally-built Release. `ditto` preserves macOS bundle metadata that `cp -R` strips; this is the canonical tool for round-tripping `.app` bundles through `hdiutil`.

## Known issues

- First open of each downloaded `.dmg` still requires right-click → Open in Privacy & Security. Will go away when we flip to signed + notarized builds.
