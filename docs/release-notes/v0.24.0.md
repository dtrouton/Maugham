# Maugham 0.24.0

_Released 2026-07-22_

Maugham can now hold your book in another language. Claude translates it
paragraph by paragraph, Maugham tracks exactly which paragraphs are still
current as you keep writing, and when every paragraph is covered you can
publish the edition — a Spanish PDF or EPUB built from the same manuscript,
without touching the English source.

## What you'll notice

- **Translated versions, tracked per paragraph.** Ask Claude to translate a
  document and the translation lives alongside it, tagged by language. Edit
  one source paragraph and only that paragraph's translation goes stale —
  Claude retranslates just what changed, not the whole document.
- **Translation Review mode.** Pick a language from View → Translation
  Review… and the editor shows the translated text read-only: amber dots
  mark stale paragraphs, untranslated ones appear dimmed in your original
  language. The new Translation pane (⌘⌥8) shows the source of whichever
  paragraph you select — and Claude's questions ("¿*vos* or *tú* for this
  narrator?") appear there for you to answer without leaving the app.
  Retranslations appear live while you review.
- **Publishing an edition is gated, loudly.** Compiling with a language
  refuses to build until every paragraph is covered and current, and the
  failure lists exactly which paragraphs need work — that list is Claude's
  to-do list. A proof-in-progress can override with `allow_stale`
  (untranslated paragraphs fall back to the source text, itemized). Edition
  metadata (title, author) comes from per-language overrides; templates and
  per-piece styles can ship `.es.tex` variants that are picked up
  automatically; republishing an edition reproduces it faithfully.
- **Claude knows the workflow.** A built-in *translation pass* skill
  teaches Claude the loop — check status, translate what's stale, respect
  your formatting, ask rather than guess on voice decisions — the same way
  the transcription and editing-pass skills work.

## Under the hood

- Three new MCP tools — `write_translation`, `read_translation`,
  `translation_status` (catalog 48 → 51) — plus a `language` tag on
  `add_query` for translation questions.
- Translations are a sidecar layer under `.maugham/translations/`
  (per-device append-only files, merged like the op log; the manuscript
  and its op log are untouched). Freshness is always derived — never
  stored — from content hashes stamped at translation time.
- Screenplay editions get structure checking: if a translated line would
  change a Fountain element (an action line coming back as a character
  cue), the compile warns.
- Publications record their language and gate mode, so the history knows
  an edition from the source book.

## Known issues

- A translation arriving from another Mac via iCloud doesn't refresh an
  open review session — exit and re-enter Translation Review to see it.
- There's no delete-translation command yet; overwrite by retranslating.
- `preview_compile` doesn't take a language yet — proof an edition with a
  full `allow_stale` compile.

## Compatibility

- No manuscript, op-log, or schema changes. Existing publish configs and
  publication history decode unchanged.
- Phone pairing unchanged — MaughamPhone 0.7.0 continues to work; no
  phone update required. Translation files sync to the phone's container
  and are ignored there.
