# Maugham 0.26.0

_Released 2026-07-23_

Editions are now first-class. In 0.25 a translated edition had no real
relationship to the book it translated — you had to juggle the version
counter and encode the language into the version string by hand. Now a
version is a family: the same book, in every language and format it ships
in.

## What you'll notice

- **One version, many editions.** Publishing v1.0 and then compiling the
  Spanish edition gives you `1.0/es` as a sibling of `1.0` — same version,
  its own language, both formats welcome. No version-counter juggling, no
  `1.0-es` version strings. The version counter only advances when you
  publish the source-language book.
- **Editions point at real versions.** Compiling with a language renders
  the newest published version by default, or exactly the one you name.
  Asking for a version that was never published — or one that only exists
  as a republish — refuses with an explanation of what to do instead. And
  to be plain about what you get: an edition compiles your *current*
  manuscript under that version's name; reproducing a past compile exactly
  is what republish is for.
- **Filenames come out right.** The compiled file carries the edition's
  real version — `Playlist-v1.0-es.pdf`, not the counter's next number —
  and a filename template using `{language}` now cleans up after itself
  for the source language (no more trailing hyphen).
- **Finding editions.** `list_publications` can slice by language (or just
  the source rows), and every entry says which language it is. Reading
  pages of a specific edition at a shared version works too.

## Under the hood

- Publication identity is `(version, language, format)`; the pre-compile
  collision guard refuses only an exact triple, and republished records
  are excluded from edition targeting in both directions.
- `compile` gains `version` (editions only); `dry_run` validates
  pinned editions with zero mutation; the resolved version flows through
  filename, PDF version stamp, EPUB metadata, and the publication
  snapshot, so two pinned editions can never silently overwrite each
  other's files.
- The publishing guide and translation-pass skill now teach the family
  model.
