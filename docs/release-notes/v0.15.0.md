# Maugham 0.15.0

_Released 2026-07-07_

Every place Maugham shows Markdown now reads it the same way. The five
separate block parsers behind the Help window, research previews, the ⌘/
syntax sheet, the phone reader, and publishing have been replaced by one
shared parser — so the same text can no longer render as a list on one
surface and marker soup on another.

## What's new

- **Research previews render more.** Notes with bullet or numbered lists,
  fenced code, pipe tables, and quotes now show them properly — lists as
  lists, code in monospace, tables as grids, quotes with an accent bar —
  alongside the images research already rendered.
- **The ⌘/ syntax sheet renders its own tables** (the Smart typography
  reference now shows as a real grid) and benefits from the same shared
  rendering as the Help window.
- **One grammar, documented.** Block recognition — headings, lists, fences,
  tables, quotes, scene breaks — is now identical on every surface; the
  in-app syntax guide describes exactly what each surface shows.

## Fixes

- **The Help window can no longer drift from its content.** A permanent test
  now verifies every bundled help document renders without any construct
  silently degrading to plain text.
- **Consistent paragraph rules.** A handful of edge cases where the same
  document segmented differently per surface (glued bullets, quotes without a
  space after `>`, `#`-without-space lines) now behave identically everywhere.
- A table or image at the very start of a block followed directly by text now
  publishes as separate blocks rather than being glued into one paragraph of
  literal text.

## Known issues

- Ordered lists display with sequential numbering on reading surfaces —
  source numbering like "5." on the first item isn't preserved (published
  PDFs have always auto-numbered).
- In the editor itself, lists and tables remain marker-styled source text by
  design — the editor shows what you typed.
