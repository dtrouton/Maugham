# Maugham 0.44.0

_Released 2026-11-02_

A fixes release: notes, history, Research tables and updates. Mac only; MaughamPhone 0.16.0 is still current.

## What's new

- **Updates arrive sooner.** Maugham now checks for an update every six hours by the clock, counting time the Mac spends asleep. It also checks when the Mac wakes and when you switch back to Maugham, if a check is due. Before, the check waited 24 hours of awake time, so a release could go unnoticed for days. Check for Updates… still checks immediately.
- **Restoring history keeps notes in step with the text.**
  - Suppose a suggestion was accepted at the moment you return to, and you have since reverted it. When a rewind, or reverting to a checkpoint, puts its text back, the note comes back accepted, not open.
  - A suggestion whose change the restore takes away is reopened. The confirmation names these notes before you commit, and the result names them after.

## Fixes

- **Notes**
  - Undoing a Reject or an Archive undoes only that decision. A note you'd answered before gets its earlier answer back.
  - A rewind no longer reopens a suggestion you'd Stetted.
- **History**
  - The rewind confirmation now counts accepted notes on paragraphs the rewind removes.
  - ⌘Z after rewinding forward leaves every note as it was.
  - Reverting to a checkpoint writes a clean file: no internal markers, and no paragraphs written since the checkpoint dropped. If the revert can't be saved, nothing is written, and the sheet stays open and says why.
- **Research tables and figures**
  - A figure that uses a Research table updates when the table changes on another device, or when Claude changes it.
  - A CSV whose first line has a stray quote mark (`5"`) now imports with the right columns.
  - If a table's formatting can't be saved, Maugham says so and tries again on the next save, without losing a change synced from another device.
- **Tables in the text**
  - A last row starting `Table:` is no longer swallowed as the caption.
  - Text with Windows line endings reads correctly.
  - A figure with a broken label (`{#fig:}`) warns at Publish.

## Known issues

- None new.
