# Maugham 0.24.1

_Released 2026-07-22_

Patch release fixing Translation Review entry.

## Fixes

- **Choosing a language in the Translation Review picker now actually
  enters review mode.** In 0.24.0 the picker appeared but selecting a
  language did nothing — the selection signal was dispatched through the
  key-window event channel from inside the picker dialog, and while a
  dialog is up the dialog itself holds key-window status, so the app
  dropped its own signal. The picker's buttons now apply the selection
  directly.

## Compatibility

- No manuscript, op-log, or schema changes. No phone update required.
