# Maugham 0.18.0

_Released 2026-07-10_

⌘Z now works on everything. Rejecting a suggestion, ticking a checkbox,
reordering tasks, even restoring from History — all of it undoes with the
same keystroke you already trust, and redoes with ⇧⌘Z. Nothing is ever
erased to make that work: an undo is a new entry in your document's
history, not a deletion from it.

## What's new

- **⌘Z undoes annotation decisions.** Reject or archive one of Claude's
  (or a reviewer's) notes and ⌘Z brings it back to Open — with your
  rejection reasoning preserved if you redo. Editing or withdrawing your
  own review note is undoable the same way.
- **⌘Z undoes task changes.** Status toggles, drag-reordering, nesting,
  body edits, creating and archiving — every Tasks-pane action is
  undoable, with a readable name in the Edit menu ("Undo Reorder Task",
  "Undo Archive Task"). A reparenting drag undoes as one step, and
  **Archive All Done** comes back as one ⌘Z, checkboxes and all.
- **⌘Z undoes checkbox clicks.** Ticking an inline `- [ ]` in the editor
  or the Tasks pane flips back with ⌘Z.
- **⌘Z undoes a History restore.** Restored to an earlier point and
  regretted it? One ⌘Z puts everything back — text, reopened suggestions
  (with their replies), and task state. ⇧⌘Z re-runs the restore. The
  History pane labels these entries "Rewind undone" so the timeline stays
  readable.
- **Undo never rewrites history.** Every undo is recorded alongside what
  it undid — the History pane and rewind timeline show the full story,
  including your changes of mind.

## Good to know

- Actions that rewrite manuscript text (accepting a suggestion, toggling a
  checkbox, restoring from History) start a fresh undo point — ⌘Z reaches
  them and anything after them, but not typing done just before. This is
  deliberate: it is what keeps ⌘Z crash-free around external text changes.
  Decisions that don't touch text (rejecting, archiving, task reordering)
  stack as deep as you like.
- History restores still leave your editorial verdicts alone: rewinding
  text doesn't un-reject a suggestion you rejected. Only *accepted*
  suggestions whose applied text a rewind removes get reopened — so status
  and text always agree.

## Compatibility

- **Update the Mac app and MaughamPhone together** (this release pairs
  with MaughamPhone 0.5.0). Projects *created* by Maugham 0.18.0 use a
  newer project format that older app versions refuse to open. Existing
  projects are unaffected.
