# Maugham 0.47.1

_Released 2026-11-16_

One fix: **Restart & Update** no longer leaves Maugham half-quit. Mac only.

## Fixes

- **Restart & Update finishes.** In 0.46.0 and 0.47.0, clicking **Restart & Update** with a project open left Maugham on screen but stuck: it never quit, the update never installed, and nothing opened or saved until it was force-quit. Maugham now quits, updates and reopens.

## Known issues

- **Installing this update from 0.46.0 or 0.47.0 still hits the old fault,** because the fault is in the version you are leaving. Either close every project window before clicking **Restart & Update**, or, if Maugham is already stuck, force-quit it (⌥⌘Esc → Maugham → Force Quit): the update then installs and Maugham reopens. Text typed after clicking **Restart & Update** was not saved; copy anything you typed since then before force-quitting.
