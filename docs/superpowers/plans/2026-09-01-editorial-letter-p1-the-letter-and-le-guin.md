# Editorial letter P1 — the letter and Le Guin

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** every ⌘R can end with an editorial letter — say-back, the one thing, what's working, habits with an exercise the writer can accept as a task, questions that also land in the queue, a scenes table in the position the piece calls for — and a beginner's ⌘R is Le Guin's, because an unassigned piece belongs to whoever holds the coach's seat.

**Architecture:** the letter is a sixth streamed report section parsed by `DiagnosticIngest` into a `Letter` value on `CompilerRun`, rendered by one `LetterSection` view that the Diagnostics pane (Author) and the round cockpit's disclosure (Review) both mount. The coach is a preset that never enters the ladder's array; the seat is a manifest field; one Mac-side resolution (`ProjectManifest.reader(forPiece:memory:)`) answers *stage / coach / nobody* for a piece and is what the orchestrator's `activePass` closure, the Author header, the empty-state promise and the cockpit label all read — so coach-lane rounds and Le Guin's signature fall out of machinery a stage run already uses. Depth becomes one shared menu mounted in both homes, with a fourth choice.

**Tech Stack:** Swift/SwiftUI/AppKit; `claude -p` (the `fable` alias is accepted by CLI 2.1.257's `--model`); XCTest via `./scripts/test.sh` (+ `swift test --package-path Packages/MaughamCore` after touching Core); headless `TestWindow` fixture for mounted tests.

**Spec:** `docs/superpowers/specs/2026-08-29-the-editorial-letter-design.md` §3.1–3.6 and §4 (as revised 2026-09-01: §4.1 the seat is a manifest field; §4.2 reader line; §4.3 depth in both homes; §3.2 letter-only questions; §3.3/§3.5 parts per voice and order; §3.4 the Add-to-intent offer). **Out of this plan:** §3.7 the ask (`answer`), §6 the ledger (`retired`, `lesson` consumption, `lessonHeading`), §5/§3.8 process and dosage (`process`).
