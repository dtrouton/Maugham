# Imprints P3 — anchors, cross-links, and the desk

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** every compiled artifact carries a stable anchor per paragraph (`p-<tag>-<¶id>`), a slugline in one body links to the same scene in every other body, the Publish desk gains an **Imprint** picker and its first in-app **Compile…** action, and every surface that names a compiled book says its imprint and its languages — closing the milestone.

**Architecture:** the AST source hands the builder its paragraphs as `(¶id, text)`; the builder stamps each paragraph's id on the *first node it produces* into a `Section.anchors: [Int: String]` map (node index → id) — an additive field, so no constructor, emitter test or identity-equivalence test changes shape. The emitters take the body's tag and the other bodies' targets and write `\hypertarget`/`id=` and `\MaughamCrossLink`/`<a href>`; the compilers compute the targets (the EPUB needs the other body's section *filename*). The desk's compile runs the same `CompileOrchestrator` the MCP tool runs, through `PublishingStores`, so the mint gate, the coverage gate and the `maughamPublicationCompleted` event (which already resets the preview picker) all come free.

**Tech Stack:** Swift/SwiftUI/AppKit; tectonic (real compiles behind `TectonicProbe.requireReady()`); XCTest via `./scripts/test.sh`; headless `TestWindow` fixture for mounted tests.

**Spec:** `docs/superpowers/specs/2026-08-27-imprints-and-bilingual-editions-design.md` §5 (anchors, cross-links), §6 (desk picker, Compile…, naming surfaces), §7 (EMISSION entries). Built on P1 (`docs/superpowers/plans/2026-08-27-imprints-p1-resolution-and-identity.md`) and P2 (`docs/superpowers/plans/2026-08-28-imprints-p2-bilingual-bodies.md`), both merged. This is the last plan: the milestone releases after it (Mac-only; the release-notes items P2's ledger carries — the wrapper's `\clearpage` pagination check on a real template, the EPUB `xml:lang` byte change — are the release's, not this plan's).

## Global constraints

1. **Anchors are additive.** `ProjectAST.Section` gains `anchors: [Int: String]` (node index → `¶id`), default `[:]`; `ProjectASTBuilder.PieceRef` gains `paragraphs: [(id: String, text: String)]?`, default nil (a source that supplies only `displayText` builds the same AST as today with no anchors). `Node`/`ProseNode`/`FountainNode` and every convenience constructor are untouched. The identity-equivalence tests in `ASTTranslationSubstitutionTests` are **untouched and stay green**: an identity translation carries the same `¶id`s, so `anchors` compare equal.
2. **The AST is byte-for-byte what it was.** For every existing fixture, the nodes built from `paragraphs` equal the nodes built from the joined `displayText` — pinned by a new equivalence test over every `ASTTranslationSubstitutionTests` fixture plus the EMISSION examples. If per-paragraph offsets cannot reproduce the joined parse for a construct, the fix is in the offset mapping, never a loosened assertion.
3. **The anchor id is `p-<tag>-<¶id>`** where `<tag>` is the compiler's `fileTag(for:at:)` (already filename-safe; `PDFCompiler.swift:308`, `EPUBCompiler` likewise) and `<¶id>` is the 4-character `ParagraphID` (alphabet `0-9a-hjkmnp-tv-z`, `ParagraphID.swift:4`). It is TeX-safe unescaped and a valid XML `id` (starts with a letter). Every compile emits anchors — single-body included.
4. **Cross-links are on scene headings only** (spec §5), from a body to every OTHER body in order; the target always exists (every body renders every paragraph). LaTeX: `\MaughamCrossLink{<target>}{\scene{…}}`, nested once per other body, outermost = first other body; XHTML: `<a href="<file>#<target>">` wrapping the heading's text. Both degrade: `\providecommand{\MaughamCrossLink}[2]{#2}` and `\providecommand{\hypertarget}[2]{#2}` are emitted in the body prologue beside `strikethroughProvidecommand` (`LaTeXBodyEmitter.swift:19-28`), so a preamble without hyperref still compiles. A single-body compile emits anchors and no links.
5. **The `\scene` macro applies `\MakeUppercase`** (`screenplay.tex:46`); the link wraps the macro (`\MaughamCrossLink{t}{\scene{…}}`), never the reverse.
6. **The desk's compile IS the tool's compile.** It constructs `CompileOrchestrator` exactly as `CompileTools.swift:141-153` does — through `PublishingStores.sharedFor`, with `ProjectStoreASTSource(projectStore:, language: nil)` — and calls `compile(format:label:languages:allowStale:imprint:)`. `maughamVersion`/`tectonicVersion` move to ONE home, `PublishToolchain` (new, `Maugham/Publish/`), read by BOTH the tool and the desk — the `"0.15.0"` literal at `CompileTools.swift:153` and the `Bundle.main` lookup at `:152` have exactly one spelling after this plan. No `DurableProgress`, no second orchestrator, no `dry_run`.
7. **One message channel.** The desk carries one `notice` slot (`DepartmentRunTests.test_theDeskCarriesOneMessageChannelAndNotTwo`); a compile's status rides the same `DepartmentRunState`-shaped machinery (`DepartmentRunState.swift:129-190`), never a second banner.
8. **Stores are never read by `DepartmentPane`** (tripwire 4, `DepartmentPaneTests.test_theSourceReadsNoStoreAtAll`); the host derives, the pane draws. The picker's value persists in `UIState.publishImprint: String?` (nil = the book), five edits (`UIState.swift` property/init/CodingKeys/encode/decode, tolerated-missing), written through `documentStore.updateUIState`.
9. **Naming is read off the record, never re-derived from a filename** (spec §6). The Exports footer joins directory entries to `PublicationStore` rows by `outputPath`; an entry with no row keeps its bare name.
10. **Mounted tests use the headless fixture** (`TestWindow.mount`, `axTexts(in:)`, premise-first assertions — `DepartmentPaneTests.swift:507-509`); no window presented outside it (`TripwireGrepTests.test_noWindowIsPresentedOutsideTheTestWindowFixture`). P1's and P2's censuses stay green. Tripwires 8, 13, 20, 21 (events go through `MaughamEvent`).
11. Every refusal has a control; disable experiment on every negative assertion, failure line quoted. **`-only-testing` takes `MaughamTests/<ClassName>`, never a path.** After each task: focused classes → COMMIT → `./scripts/test.sh` as a blocking foreground command → report. `./scripts/test.sh full` before merge; whole-branch review before merge.

## Task 1 — the anchor seam: `PieceRef.paragraphs` → `Section.anchors`

**Files:** `Maugham/Publish/ProjectAST.swift` (`Section` :13-25); `Maugham/Publish/ProjectASTBuilder.swift` (`PieceRef` :6-19, `buildSection` :37-47, `parseProse` :51-58, `parseFountain` :118-131); `Maugham/Publish/ProjectStoreASTSource.swift` (`pieceRef(for:)` :78-105 — the nil-language path switches from `materialize()` to the same `(sequence, paragraphs)` split `translatedDisplayText` :121-154 already reads; both paths hand `paragraphs`); `Packages/MaughamCore/Sources/MaughamCore/MarkdownBlockParser.swift` (additive `parseWithLineRanges(_:) -> [(block: MarkdownBlock, lines: Range<Int>)]`, `parse` becomes `parseWithLineRanges(…).map(\.block)`; NO case widening — seven pattern-match sites would break); `Maugham/Publish/FountainNodeMapper.swift` (additive `mapWithFirstLines(_:) -> [(node: FountainNode, firstLine: Int)]` — the action buffer's first line is the buffer's START (`flushAction` :46-52), a character block's first node takes the block's first line, `dualDialogue` the left block's; `map` becomes `mapWithFirstLines(…).map(\.node)`); tests `MaughamTests/Publish/ProjectASTAnchorTests.swift` (new), `Packages/MaughamCore/Tests/…/MarkdownBlockParserTests.swift` (line-range cases), `MaughamTests/FountainNodeMapperTests.swift` (first-line cases), `MaughamTests/Publish/ASTTranslationSubstitutionTests.swift` (UNTOUCHED — assert by running it).

**Contract.**
```swift
// ProjectAST.Section
public let anchors: [Int: String]          // node index → ¶id; [:] when the source gave no paragraphs
public init(pieceID:title:mode:nodes:anchors: [Int: String] = [:])

// ProjectASTBuilder.PieceRef
public let paragraphs: [(id: String, text: String)]?   // sequence order; nil = displayText only
public init(pieceID:title:mode:displayText:paragraphs: … = nil)
```
Requirements:
- When `paragraphs` is nil: exactly today's build, `anchors == [:]`.
- When present: the builder parses `displayText` exactly as today (so the nodes are identical — constraint 2) and computes, for each paragraph k, its line span in the parsed text: `stripped = MarkdownDisplayFilter.stripAnchors(displayText)` is what is parsed today; establish the span by re-deriving the joined text from `paragraphs` (`texts.joined("\n\n")`) and asserting in the builder that `stripAnchors(joined) == stripped` — if it is not (a source whose `displayText` was not the paragraph join), fall back to `anchors == [:]` and never guess. Spans: paragraph k occupies lines `[start_k, start_k + lineCount(text_k))` in the joined text, `start_{k+1} = start_k + lineCount(text_k) + 1` (the separator's blank line). Prose: each block's `lines.lowerBound` falls in one span → that paragraph's id goes on the FIRST node produced from the first block in the span (a paragraph can yield several blocks only for constructs spanning no blank line — a heading followed by text is two paragraphs in the op log). Fountain: each node's `firstLine` → span → id on the first node in the span. `stripAnchors`'s outer trim can shift line 0 — measure and account for it (a leading blank line in paragraph 0).
- `ProjectStoreASTSource.pieceRef` hands `paragraphs` on BOTH paths: nil-language = `sequence.map { ($0, paragraphs[$0]!) }` (missing id → skipped, as `Materializer` skips it); language = `derived.entries.map { ($0.paragraphId, displayText(for: $0)) }` (Fountain via `TranslatedFountainStructure.displayText(for:)`, prose via `translatedText ?? sourceText` — the SAME strings it joins today).

**Tests:** anchors on a Fountain block (cue + dialogue → one id on the cue node, none on the dialogue), coalesced action (two action lines in one paragraph → one id), a prose blockquote, the fenced-code-with-internal-blank-line fixture (one id), a two-paragraph prose doc (two ids, on indices 0 and 1); `paragraphs == nil` → `[:]` and identical nodes; the equivalence pin (constraint 2) over every `ASTTranslationSubstitutionTests` fixture body: nodes from `paragraphs` == nodes from `displayText` alone; `parseWithLineRanges` line ranges tile the input for each existing `MarkdownBlockParserTests` fixture; `mapWithFirstLines` first lines are non-decreasing and the action buffer reports its start. `ASTTranslationSubstitutionTests` runs green untouched (name it in the report).
