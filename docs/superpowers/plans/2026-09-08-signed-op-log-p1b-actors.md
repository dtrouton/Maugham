# Signed op log P1b — actors: four keys on one device

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** every op-log and translation line on this device is signed by the key of the *actor* that wrote it — `author` (the writer's own acts, including wiki-rename and search-and-replace), `assistant` (anything through MCP), `translator` (the translation pipeline and `write_translation`), `maugham` (the app acting on its own: task-priority rebalance) — so the role is in the key rather than a label, a hand-built device string is a compile error, and no production op is unsigned any more. Ruled by Denver 2026-09-08 on the P1 handoff's decision #7 (*"lets use the terminology 'assistant' for anything through the mcp … translations get a special role of 'translator' … optimisations should be signed as Maugham itself … search and replace is an automation of the writer"*).

**Architecture:** `DeviceActor` is a closed enum in MaughamCore and `DeviceIdentity` gains `actor:`; each actor is its own enclave key blob under the same `device/` folder and its own device id `<actor>-<16hex>` (the author's included, so a file reads as itself: `<doc>.author-<16hex>-<8hex>.jsonl`). `LocalIdentities` is the device's four identities in one value; `OpLogStore` signs with whichever local key an op's `device` names, trusts all four, and seals every local actor's file it has written. `Document.load` takes an actor in production (the `device: String` overload becomes test-only); the rebalance sentinel becomes the `maugham` identity with the undo guard reading `session` instead. `TranslationStore` writes go through the chained `JSONLAppendStore<TranslationRecord>` under the translator (pipeline, `write_translation`) or the author (the review pane's own edits). No format change: `prev`, seal lines, `.lines` records and the state file are exactly P1's; the state file belongs to the DEVICE (the author key's fingerprint). Spec §4.1 gains the actor row; ADR 0032 an addendum; P2's registry will admit a person, a device and an actor.

**Tech Stack / gates:** as P1 — Swift 6, CryptoKit; `swift test --parallel --package-path Packages/MaughamCore`, `./scripts/test.sh`, `./scripts/test.sh phone`; Release build before merge. **Spec:** `docs/superpowers/specs/2026-09-05-signed-op-log-design.md` §4.1/§4.8/§4.9, amended by Task 5. **P1 handoff:** `docs/superpowers/notes/2026-09-07-signed-op-log-p1-handoff.md`. **Branch:** `claude/signed-op-log-p1b-actors-2026-09-08` off local `main` at `2ead6bf9`.

## Global constraints

1. **Four actors, closed.** `DeviceActor: String, CaseIterable, Sendable { case author, assistant, translator, maugham }` — raw values are the id prefixes and the blob suffixes. A fifth actor is a spec amendment, not a code change; nothing switches over it non-exhaustively.
2. **Ids and files.** `deviceId = "\(actor.rawValue)-\(16 hex)"`; `fingerprint` unchanged (64 hex of the key); `slug = DeviceSlug.make(from: deviceId)`. Blobs: the author keeps `device-key.blob`/`device-token` (nothing minted in production yet, but the names are already in the docs); the others are `device-key.<actor>.blob`/`device-token.<actor>`. One `op-log-state.json`, `identity` = the author's fingerprint (the device).
3. **Every P1 invariant holds verbatim** (plan `2026-09-07-signed-op-log-p1-integrity-and-the-device.md` constraints 1–11): no software key in production, no keychain/entitlement/profile, the wire format, persist-before-write, the crash-window rule, `.lines` never returnable, tripwire 33, all three gates per Core-touching task, disable experiments on every negative assertion.
4. **A device chains only its own files, now four of them.** `OpLogStore.append` chains and seals iff `op.device` equals one of `LocalIdentities`' four ids, signing with THAT actor's key; any other device string appends plain and logged (P1's C1 rule, widened). `trusted` on every read is *any of the four fingerprints*. History's "N changes from another device" therefore never counts a local actor.
5. **No hand-built device string reaches `Document.load` in production.** The `device: String` overloads become `internal` (332 test sites keep them); production calls `Document.load(url:actor:session:presenter:)`. A census forbids `device: "` at any `Document.load(` call site under `Maugham/` and `MaughamPhone/`, with a planted offender.
6. **Search-and-replace, wiki-rename, statements, checkpoints, the editor: `author`. MCP annotation and task tools: `assistant`. `write_translation` and the pipeline: `translator`; the Translation Review pane's own edits: `author`. Task rebalance: `maugham`**, recognised by `session == TaskDeriver.rebalanceSentinel` (the string stays as the SESSION marker; no `SynthesisSource` case, so no schema bump).
7. **The phone is the `author`** on its own device (its captures and accept/reject are the writer's acts); it mints only the one key it uses.
8. Prose counts about lists are forbidden; name members. Nothing under `Maugham.xcodeproj/`, `.agents/`, `.codex/`, `AGENTS.md`, `.superpowers/` is committed.
