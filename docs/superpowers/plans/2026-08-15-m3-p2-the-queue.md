# M3 P2 — The Queue: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Review's annotations pane becomes the working queue — triage (do/decline/discuss) and Stet as op-logged writer verbs with undo, multiselect + bulk operations, a cross-document scope grouped by piece, pass-stamping of new annotations, the board's open-notes column, `ActivePassMemory`'s first reader, and the advisory-order nudge.

**Architecture:** Two new `OpKind` cases (`annotationStet`, `annotationTriage`) ride the existing annotation op machinery — `Annotation` stays a pure projection (no annotation wire format exists; the deriver computes triage and the pass stamp from `Op.Provenance` optionals, three shipped precedents). Cross-document reads follow the Tasks-pane aggregation shape exactly (open docs live, closed docs via `OpLogStore.loadSyncMerged` → derive, mtime-keyed cache); the board gets its deferred open-notes column as passed-in values (tripwire 4 intact). MCP widenings and docs/guide are P3's — this plan does not touch the tool catalogue.

**Tech Stack:** Swift / SwiftUI / AppKit; MaughamCore SPM package; XCTest.

**Spec:** `docs/superpowers/specs/2026-08-14-m3-review-passes-design.md` (§5 is this plan's scope; §4's open-notes column and §2's advisory nudge are its named carries from P1). P1's plan for what is already built: `docs/superpowers/plans/2026-08-14-m3-p1-spine-and-board.md`.

- **ADR 0023 rules bind every new verb**: undo appends a compensating op (never truncates); inverse decisions live in typed factories (`AnnotationInverse`), compiler-exhaustive; every undo/redo closure re-checks derived state at fire time and declines as a LOUD no-op (`documentLog` + `notifyWriter`, RULING-22); redo closures forward the live weakly-captured `UndoManager`; `removeAllActions` never runs inside an open manual undo group — which is why bulk operations register per-item undo steps and NEVER wrap accepts in an undo group.
