# M3 P3 — The Loop: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The compiler's half of M3 — a ⌘R while a pass is active becomes a numbered **round** in the diagnostics sidecar; the next report **leads with resolved / persisting / new** vs the previous round, computed app-side; **Fresh Eyes** (⌘⇧R) ends the warm session and reads the piece whole, cold; each round's briefing asks whether the draft **drifted from the declared intent** and the strip carries a quiet mark until a run clears it or the statement is edited; the assistant column widens to Author + Review; `get_outline`/`list_annotations` report what P1/P2 built; and the docs/guide catch up to the whole milestone.

**Architecture:** Every compiler change is additive to the existing per-(document, device) sidecar — `CompilerRun` gains optional stamped fields (pass, round, fresh-eyes, drift verdict) through its hand-written tolerant decoder, and `FileContent` gains a capped round-history ring of *fingerprints* beside the existing `clauseHistory` ring, so "since last round" is a pure comparison over records (the `DriftDetector` mould) and never a background process. The active pass reaches the orchestrator as one new `Environment` closure copying the `intent:` idiom. Fresh Eyes is the existing retire-and-respawn path (the model-change precedent) plus a `since: nil` delta. The MCP widenings call the projections P1/P2 already shipped (`ReviewStatus.derived`, `Annotation.triage`/`.reviewPassId`) — zero new tools, zero new writes.

**Tech Stack:** Swift / SwiftUI / AppKit; MaughamCore SPM package; XCTest.

**Spec:** `docs/superpowers/specs/2026-08-14-m3-review-passes-design.md` — §6 (rounds, since-last-round, fresh eyes, drift), §8 (MCP), §9 (assistant column), §11 (docs). Survey of the built surface: this plan's signatures were read off the working tree 2026-08-15; P2's built API is in `docs/superpowers/notes/2026-08-15-m3-p3-handoff.md`.

## Global Constraints

- **No schema bump.** No new `OpKind`, no manifest change — the sidecar has no version field and every new field is optional-with-tolerant-decode (the house discipline at `Diagnostic.swift:152-164`). The standing paired Mac+phone release (v7) is untouched; nothing here moves it.
- **The compiler reads and never writes** (ADR 0028). The two-flag confinement (`--tools ""` + `--allowedTools`) is not touched by any task; `CompilerAllowlistTests`' census must pass unmodified. Drift is a briefing question and a sidecar verdict — the mark is **app-rendered**, never model prose (ADR 0027 §1, `IntentStrip`'s doc comment and `IntentStripTests`' census).
- **Keystroke-only triggers.** ⌘R stays the only ordinary trigger; Fresh Eyes is a second *keystroke* (⌘⇧R), writer-initiated, spec-authorized ("a run variant beside ⌘R"). No timers start anything; every timer still only ends a session.
- **Preview discipline** (`DiagnosticsStore.swift:165-181`): `preview` persists nothing, feeds no ring, sets no badge. The round-history ring and the drift verdict follow the same rule — **only `replace` writes them**; one streaming run must contribute exactly one round. `dismiss`'s refusal-while-previewing precedent applies to any new mutator.
- **MCP: zero new tools, zero new writes.** Count `MCPToolCatalog.all`; `MCPToolsListSmokeTest` holds for free. MCP never joins the pass-state writer census (`PersonaPaneRegistryTests.passStateWritingFiles` — three files, closed).
- **No phone surface.** Nothing here compiles into MaughamPhone.
- **Naming care:** `DriftDetector`/`DriftFinding` (clause-strain *pattern* across runs, M2 Stage 3) already exist and KEEP their meaning and their pane line. The new §6 concept is **intent drift** — a per-round judged verdict. New types spell it `IntentDrift…`; never overload the bare word "drift" in a type name.
- **Gates**: `./scripts/test.sh` for iteration; `./scripts/test.sh full` pre-merge — **NO skips; the MCP wall-clock flake family is CLOSED and a red MCP test is a real signal.** `swift test --parallel --package-path Packages/MaughamCore` after touching the package (Task 8 does not; nothing here should). Reviewers are briefed "report, don't fix." Demand falsification in every review: a guard's test must go red when the guard is deleted. Opus for Tasks 1–6; sonnet acceptable for 7–9.

**Decisions of record made by this plan** (each traceable to the spec or a survey finding; flag disagreement to the controller rather than silently deviating):

1. **A round's comparison lane is (document, pass id).** "Since last round" compares against the most recent prior round with the SAME `passId` — a passless run (`passId == nil`, no active pass) is its own lane. A ⌘R with no active pass is an ordinary M2 run: it still records (round nil) and supersedes normally, but mints no round number and gets no since-last-round section.
2. **The comparison is computed twice, from one spelling.** At briefing time the app hands the model the *previous* round's findings partitioned by "paragraph since edited / untouched" (the sidecar's standing content IS the previous round, read before `replace`); after the run the pane derives resolved/persisting/new by fingerprint matching between the ring's last same-pass record and the new outcome. Both go through `RoundHistory.swift`'s pure functions; nothing is stored beyond fingerprints.
3. **Fresh Eyes keeps the standard, drops the memory.** Briefed on essay + derived world + bible + pinned/palette listings (the standard and the established world); omits the since-last-round section; the session is retired first so no conversation history survives. It IS a round (mints pass + round N) tagged `freshEyes`.
4. **The drift section is named `intent_drift`** — `DiagnosticIngestTests.test_v2MintsNoDriftNote` (which pins its ABSENCE from the v2 contract) is deliberately inverted, with a comment citing this plan. The verdict is a two-value wire string (`holds` / `drifted`) parsed or-nil, `TriageMark`'s no-unknown-case discipline.
