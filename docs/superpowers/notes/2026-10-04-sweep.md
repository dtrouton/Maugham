## 2. Emergent / cross-cutting finding (the synthesis payoff)

**Ruling U's starter-yield lives only in `Posture`; the permit/stamp cannot see it — and two write paths are gated by the stamp, not the posture.** Two facts collide across maps: (a) *bug-hunt map* — `LocalWritePermit.unsettledStarter` "widens nothing and refuses nothing: `allows` answers exactly as it would without it; what a surface may OFFER is the posture's" (`LocalWritePermit.swift:80-82`), so `Document.mayWriteItsText` (`= allows(.op(.typingBurst))`, `Document.swift:258-260`) returns `true` for a book author over an unclaimed piece; (b) *tracer map* — every yield-aware surface/door reads `posture.allows(.writeText)`, **except** the Recovered-History *Append*, whose SURFACE and DOOR are the same permit-only `mayWriteItsText`. The editor is yield-locked (Ruling U) while a sibling manuscript-write path in the same History flow is not. Neither agent's findings list alone reaches it — the bug-hunt named the class, the tracer walked the doors.

### F1 [Medium] The Option-A / Ruling-U starter-yield is bypassed on the Recovered-History *Append* path — **VERIFIED against source**

`RecoveredHistorySheet.mayAppend(to:)` returns `document.mayWriteItsText` (`Maugham/Views/RecoveredHistorySheet.swift:36-38`), and that same function is both the surface gate and (per its own doc-comment, "**The door**") the write door. `mayWriteItsText` is permit-only (`Maugham/OpLog/Document.swift:258-260`), and `unsettledStarter` deliberately widens/refuses nothing (`Packages/MaughamCore/Sources/MaughamCore/LocalWritePermit.swift:80-82`) — the yield is applied only when a `LocalWritePermit` becomes a `Posture` (`DocumentStore+Posture.assemble`). So on a **book author's** Mac, over a piece **someone else started that nobody has claimed** (`unsettledStarter != nil`), `mayAppend == true`: the sheet offers *Append to End* / *Append All* and the append succeeds, writing a new manuscript paragraph via `insertParagraph`. Because Option A's partition treats a book author's applied manuscript text as *claiming* the piece (`Permit.claimsAPieceByWritingItsText`), that one click sets the starter's held words aside on every Mac — the exact harm Ruling U's *Edit Anyway* friction exists to gate, performed here with no yield prompt. The editor membrane, History *Restore*, find-replace, rename and the round Run all read the yield-aware posture; this path reads the stamp on both layers, so nothing catches it. — `Maugham/Views/RecoveredHistorySheet.swift:36-38` + `Maugham/OpLog/Document.swift:258-260` + `LocalWritePermit.swift:80-82` — fix-shape: gate `mayAppend` on `documentStore.posture(forDocId:).allows(.writeText)` (yield-aware) rather than `document.mayWriteItsText` — effort: **S**. Class: **silently-unwired-after-refactor** (Ruling U retrofitted path-by-path; this path skipped). Scope discipline: nothing is *lost* — the starter's text is held, not deleted (constitution must #1 holds); the defect is that a product decision Denver ruled (the yield + Edit Anyway) is bypassed. Reachability is narrow (a book author must hold recovered orphan history for a piece she is yielding on), which is why it shipped green.
