### 3.1 Context-window economics (carried, the dominant maintainability risk)

- **F-A [Medium] `ProjectWindow.swift` is 4704 LOC — grew +63% since the last audit scheduled its split (F5).** The `ProjectWindow` struct alone is lines 23–3711 (~3688 lines); 15 `View`/`ViewModifier` structs live in the file, four of them still nested inside the struct. Every edit to the window loads all 4704 lines; it is the #1 churn hotspot (26 commits this window) precisely because the persona shell, the publish-department wiring, and the compiler-flash sink all land here. — `Maugham/Views/ProjectWindow.swift:23-3711` — fix-shape: extract `ProjectWindow+Chrome.swift` (the modifiers) and `ProjectWindow+Columns.swift` (the `binder/content/detail/inspector` routing builders), mirroring the completed EditorCoordinator split — effort: L.
- **F-B [Medium] `CanvasRenderer.draw` remains a single ~695-line function** (prior F6, unaddressed) — `Maugham/Canvas/CanvasRenderer.swift:~973-1668` — fix-shape: split into `drawRegions`/`drawTethers`/`drawNodes`/`drawLines`/`drawChrome` static helpers — effort: M.
- **F-C [Medium] `CanvasView.swift` (2289 LOC) is still one `struct CanvasView: View`** (prior F7, unaddressed) — fix-shape: move `handleClick`/`handleDrop`/`handleDrag`/`deleteSelection` clusters into a same-module `CanvasView+Input.swift` extension — effort: L.

### 3.2 Publish department — youngest-edge Lows (all new this window)

- **F-D [Low] `EditionStatus.documentRows` per-document annotation load is unconditional and throwing, and is now amplified by the stored-role union: one unloadable manuscript chapter fails the ENTIRE `languageRows` derivation** — the desk keeps stale rows and the `translation_status` MCP tool errors, rather than degrading a single chapter. The `withAnnotationDocument` fetch (`EditionStatus.swift:128-133`) precedes the `languages.isEmpty` skip, and cast-management's role-language union (`:118`, added this window) makes `languages` non-empty for every chapter as soon as one translator role exists — so the walk now visits (and can throw on) every chapter of a role-only edition. — `Maugham/Publish/EditionStatus.swift:110-181` — fix-shape: make the per-doc load fault-tolerant (skip/degrade one unloadable chapter, not the whole desk + tool) — effort: S–M.
- **F-E [Low] `EditionStatus` doc-comment is now internally contradictory.** Lines 104–109 still assert "a document with neither a translation file nor an open query… contributes nothing," but the role-union block at 114–118 (added this window) explicitly makes such a chapter contribute a zero-row when a translator role is stored, and the file-less arm at 144–159 renders it. The two comments in the same file now disagree about the behavior. — `Maugham/Publish/EditionStatus.swift:104-118` — fix-shape: reconcile the earlier comment to the role-union behavior (114–118 is the true one) — effort: S.
- **F-F [Low] Edition-brief language tag is not validated at the filename choke point** — `StatementLookup.newPath(.editionBrief(lang), .project)` guards only `!lang.isEmpty` (`StatementLookup.swift:52-54`) and `ProjectStore.createStatement` writes `url.appendingPathComponent("editions/<lang>.md")` with no further check (`ProjectStore+Statements.swift:216-218`). A `lang` containing `../` or `/` would escape the project root. **Not reachable today** — every current caller validates first (`DepartmentCastSheet.canConfirm`, `DepartmentPaneHost.addLanguage`, `read_edition_brief`, `QueryRuling` reading a translator-minted-and-validated tag) and the outbound report can never choose a language — so this is a missing defense-in-depth layer, not a live escape. — fix-shape: gate the language segment with `TranslationRecord.isValidLanguageTag` inside `newPath`/`createStatement` so path safety does not depend on every caller — effort: S.
- **F-G [Low] `DepartmentPaneHost.addLanguage` de-dupes against derived `@State languages`, not the live manifest** — a rapid second Add-Language before `derive()` re-runs can slip past the "already on the desk" notice (`DepartmentPaneHost.swift:399-404`). Harmless: `translatorRole(for:)` is idempotent, so no second row and no second person result — only the friendly notice is missed. — fix-shape: check `store.manifest.storedTranslator(for:)` instead of the derived array — effort: S.

### 3.3 Compiler review loop — one two-features interaction

- **F-H [Low] The annotation mint dedupe is cross-lane, but `SinceLastRound` counts per-lane, so a round can report "0 new · 0 persisting" for a concern it actually engaged.** `mintAnnotations` dedupes an open finding against ALL passes' open compiler notes by fingerprint (no pass filter, `CompilerEnvironment+Project.swift:262-264`), while `SinceLastRound.compute` filters `new`/`persisting` by `reviewPassId == passId` (`RoundHistory.swift:226-253`). A Line round that re-finds a question already open in the Structural lane therefore mints nothing AND counts it in neither lane's since-line. Internally consistent with the "one finding, one home" design, and the writer still sees the note in the other lane's queue — a genuine two-correct-features interaction where the since-line under-represents the round's engagement. — fix-shape: surface cross-lane matches in the since-line ("N also open in other lanes"), or document the intended under-count where `SinceLastRound` is defined — effort: S (doc) / M (count).

## 5. Refuted / resolved suspicions (so the next sweep doesn't re-chase)

- **Session teardown missed on a window-ending path** (fire-and-forget × window-death class) — **REFUTED**: all three `ClaudeCLISession` owners (Compiler/Translator/Designer) reach `shutdown()` on app-quit + MCP-toggle-off (`CompilerRunModifier.swift:60-70`) and `detach()` on window-close, liveness-guarded, before the stores are nil'd (`ProjectWindow.swift:380-387`); `shutdown` and `detach` are used correctly and not interchangeably; `deinit` is nonisolated and does not pretend to reap. Verified independently by both the bug-hunt and the tracer.
- **Confinement weaker on the translator/designer than the compiler** — **REFUTED**: all three spawn through the identical `ClaudeCLISession` initializer; `--tools ""` + `--strict-mcp-config` + read-only `--allowedTools` apply unconditionally (`ClaudeCLISession.swift:396-419`). There is no weaker spawn path. `CompilerAllowlist` (33 tools) contains no statement/manuscript/canvas writer.
- **The compiler writes manuscript/statement text** — **REFUTED**: the compiler reads and never writes; every write-back (`mintAnnotations`, `TranslationWritePipeline.perform`, `DesignProposalStore.stage`) is reachable from exactly one arm, past a successful parse — a died/timed-out/gibberish turn has no path to writer data (ADR 0029).
- **Designer report path escape** — **REFUTED**: guarded at parse (`DesignerReport.isSafePath`, rejects leading `/`/`~`, `..`, embedded null, `config.json`) AND at promotion (`ProposalPromotion.resolve`, `standardizedFileURL`-prefix check).
- **Finalize/Revert reversibility inversion** — **REFUTED**: `finalize` is the sole irreversible step, gated on `status == .approved`; `revert` is a stored reversal (not `NSUndoManager`); the single project-wide backup slot is enforced to defeat the "layered promotions lose the originals" bug.
- **Round ring files a run as its own previous round** — **REFUTED**: the `finishedBeforePreview` shadow holds the last finished run while a preview stands in `byDoc`, so `replace` files the correct previous round.
- **Translator whole-document query loops unbounded** — **REFUTED**: every run is writer-click-triggered; no timer starts a run in any of the three orchestrators (`DesignerOrchestrator` even pins `test_noClockStartsARoundInThisFile`). An empty translation is refused (`TranslatorReport.swift:122,127`). Re-mint of a query is bounded by human clicks — an accepted gap, not a loop.
- **Doc/prose-count drift from the milestone** — **REFUTED / clean**: MCP count (56), tripwire rows (32), editor presets (Perkins/Lish/Gould/Argus), translator+designer presets (Cortázar/Baudelaire/Tieck/Motoyuki/Tschichold), 300s compiler timeout, 5-deep rounds ring, `editionBrief` as the third `Statement.Kind` all match source.
