# M2 Task 0 — the spike, measured

*2026-08-04, on the dev machine, against `claude` 2.1.221 at
`~/.local/bin/claude` and the running stable Maugham app. Spec:
`docs/superpowers/specs/2026-08-04-m2-author-compiler-design.md` §10.*

**Verdict: the warm session is real, the flags compose, and the socket takes
two clients. No re-route to the `--resume` fallback.**

## Measurements

1. **Warm multi-turn session** (`--input-format stream-json`
   `--output-format stream-json`, one process, two user turns over stdin):
   turn 1 in **3.0 s** (includes CLI spawn), turn 2 in **1.3 s**. Both results
   carry the same `session_id`. The spec's 2–4 s first-note budget holds.

2. **Fully composed** — the same warm shape plus `--mcp-config`
   `--strict-mcp-config` `--allowedTools mcp__maugham__list_projects`
   `--model haiku`: turn 1 **called a real Maugham tool through the bridge**
   (`list_projects` → correct answer) in 8.0 s; warm turn 2 in 1.5 s.

3. **Socket concurrency** — structural: `MCPServer.acceptLoop`
   (`Maugham/MCP/MCPServer.swift:123-138`) spawns a detached task per
   connection and immediately re-accepts (`listen(fd, 5)` at :81); half-duplex
   is per-connection only. Live: the spike's client ran while this session's
   own Maugham MCP connection was open — two simultaneous clients, both
   served.

4. **Bridge config shape** (what the setup sheet writes, and what the runner
   should write to a temp file per session):
   `{"mcpServers": {"maugham": {"command": "<app>/Contents/MacOS/maugham-mcp",
   "env": {"MAUGHAM_MCP_SOCKET": "<path>"}}}` — env optional when the default
   socket is wanted (`ClaudeDesktopConfig.swift:72-75`).

5. **Liveness probe**: a JSON-RPC line for an unknown method (`ping`) gets
   `-32601` back — a cheap is-the-server-alive check if the runner ever wants
   one. The Dev-variant socket file can exist while nothing listens; existence
   is not liveness.

## Consequences for the plan

- Build the warm-session runner as designed (spec §3.4); keep the seam so
  `--resume` stays a swap.
- The stream-json event stream interleaves `system`/`assistant`/`result`
  events (and `rate_limit_event`); the parser keys on `type == "result"` per
  turn and must tolerate unknown event types.
- `--strict-mcp-config` should be part of the runner's invocation — it stops
  the writer's personal MCP servers from leaking into a Maugham-spawned run.
- Cost observed: ~$0.01–0.02 per trivial haiku turn, `total_cost_usd` is
  reported per result event — worth surfacing nowhere (understated), but the
  ADR records that runs bill the writer's login.
