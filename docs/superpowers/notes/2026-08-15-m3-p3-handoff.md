## P3 scope (spec §6, §8, §9, §11) + named carries

Spec sections, in the spec's own words — read them, don't trust this list:

1. **Rounds** (§6): a ⌘R while a pass is active records (pass id, round N)
   in the compiler's existing per-(document, device) diagnostics sidecar.
   ⌘R stays the ONLY trigger (M2's rule; constitution: muscle memory).
2. **Since last round** (§6): the next report leads with
   resolved/persisting/new vs the previous round — computed APP-SIDE from
   the sidecar, handed to the model in the briefing (the model confirms,
   never reconstructs).
3. **Fresh eyes** (§6): a run variant beside ⌘R — ends the warm session,
   starts cold, reads the piece whole, briefed on intent + rulings but NOT
   prior findings/rounds; tagged in sidecar + report header.
4. **Drift, judged** (§6): each round's briefing asks whether the draft
   drifted from the declared intent; verdict lands in the sidecar; the
   intent strip carries a quiet "intent may trail the draft" mark until a
   run clears it or the statement is edited. No timers, no heuristics; the
   compiler stays read-only (ADR 0028 — the two-flag confinement is a hard
   invariant, and `CompilerAllowlistTests`' census will catch a widening).
5. **Assistant column widens to Author + Review** (§9): one predicate
   spelling on `Persona` (the `editsResearchInTheCentre` discipline);
   Plan/Publish stay without it; the one-width rule untouched.
6. **MCP widenings** (§8): `get_outline` gains per-piece pass states + the
