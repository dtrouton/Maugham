## What 1A owes

**Intent as an op-logged artifact with derived structure.** Scope is **project *and* per-piece**. Form is **freeform prose, never a form** — the spec records why: named slots are precise and nobody fills them in. Claude derives the checkable structure from the prose.

**Why it needs history, in the spec's own words:** review's job is to compare a draft against *the intent you started with*, and craft intent today is a markdown doc under `research/` where mutations are **not** op-log backed — so there is no "as of when I wrote this chapter". Promoting it gives that baseline free, forever, **with no freezing ceremony**. **History Rewind already renders this UI.**

**Visual language is the same object**, and the milestone owes it a consumer (see the second protection above).

## Six things that will bite

1. **It forces a paired Mac + phone release.** A new `OpKind` bumps the manifest schema, and an **older phone build refuses to open the project at all** — refuses, not degrades. Mac and phone ship together, as they did for schema v2 and v3.
2. **There is a dormant consumer already built, and 1A is what makes it live.** `RegionBinding.references(forPiece:)` was built in 1C-b as spec §4.4's bridge to the reference rail and was **measured at zero production callers** during 1C-c2a. That is this area's fifth built-and-unreachable half and it is deliberate. **Count its callers before calling 1A done** — every one of the previous four was found by a caller count and never by a test.
3. **Promotion already writes into craft intent, so 1A changes under a live consumer.** `PromotionTarget.intentStatement` is find-or-create at a fixed title with the body appended, and `Promotion.piece`'s precedence rules decide where it lands.
4. **And there is a live defect in that seam, already recorded.** `craftIntentItem(forPieceId:)` finds an existing intent doc by the piece's research **prefix**, which is nil for anything that is not a Collection loose piece — so an intent created under a novel chapter's shared-plus-link routing lands in shared `research/` where that lookup never looks, the *next* promotion finds nothing and mints a second, and the writer's accumulated intent is silently in two files. 1A is the slice that should resolve this rather than inherit it. *(Recorded in 1C-c2a; verify against source before acting.)*
5. **Undo must span the new op kind.** ADR 0023: ⌘Z covers every op kind via compensating ops (`annotationReopen`, inverse factories, `OpUndoRegistrar`). A new `OpKind` owes its inverse.
6. **The canvas is Mac-only and stays so** (spec §9), but the *spine* is not — intent is manifest-and-op-log state the phone reads. Anything touched by both goes through a shared `MaughamCore` implementation (tripwire 19), and the reach-around tripwires catch the known bad spellings.

## How to run the slice — what this session actually paid for

**Build the first half of the plan, then re-derive the second against the built code.** Measured on 1C-d: the re-derived half's ~90 signature citations were checked by an independent reviewer and **zero were wrong**, while the pre-written half was corrected **four times** by implementers who found reality differed. Put the re-derivation in the plan as its own task rather than splitting the milestone.

**A plan carries contracts, symptoms and verified signatures — never function bodies.** Quote a signature only if you read it out of the tree that day, and cite `file:line`.

**Tell implementers that refusing a stated ruling they can falsify is the standard.** Two did on 1C-d and both were right; one changed the plan, the other stopped writing a third wrong prose description and asserted the behaviour with a test instead.

**Reviewers write their verdict to a file before replying.** Agents went idle without reporting three times this session and the file is what survived every time.

**Six mechanical rules, each of which cost a task:**
- `./gen.sh` before any count you quote — a run without it reported ~3,725 tests "green" containing **neither** new test file, and `-only-testing` against the stale project ran **0 tests and exited 0**.
- `-only-testing` with a *folder-shaped* path runs zero tests and exits 0; suite paths are flat.
- A disable experiment must **assert its patch applied** — one that silently matched nothing ran against unmodified code and reported green, which reads exactly like "the test cannot see its subject".
- Never `git checkout -- <file>` to revert an experiment mid-round; HEAD is the pre-round commit and it takes the round's other edits with it. Hit twice.
- Never `git add -A` on a shared branch.
- **The controller does not edit the working tree while an implementer is live in it.** Mine were swept into someone else's commit.
