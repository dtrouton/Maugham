## What shipped

**The whole M2 bundle** (spec `2026-08-04-m2-author-compiler-design.md`):

- **The loop.** ⌘R ("Check Writing") runs a warm `claude -p` session over the
  op-log delta; ¶-anchored diagnostics land in the Diagnostics pane (⌘⌥D,
  Author's first pane). Warm turn measured 1.3–1.5 s; the session dies on
  toggle-off / project close / quit / idle, and is confined by **two flags**
  (`--tools ""` empties the built-ins; `--allowedTools` + `--strict-mcp-config`
  scope the MCP set to 34 enumerated reads).
- **Four fates**: fix (self-dismissing on the exact-match anchor), ignore
  (next run replaces), promote (a ¶-anchored op-logged task, schema untouched),
  and **answer** — your "that's deliberate, because…" becomes a paragraph of
  the piece's intent statement, minted if absent, and the next run reads it.
  Drift runs the other direction: a pinned anchorless note saying the intent
  may be stale.
- **The surfaces**: the intent strip (piece-first signature line over the
  prose, Author only, absent when no intent, hides with ⌘\); the References
  pane (⌘⌥E — linked research ∪ canvas-clustered, including self-bound cards
  after the projection widening) and the assistant column (study one pin
  between binder and editor); the per-project model gear (Fast/Standard/Deep).
- **ADRs 0027/0028** + the constitution boundary-note amendment; guide topic;
  roadmap entry (PENDING SMOKE).

## Two decisions held for Denver

1. **The assistant column mounts in every persona.** ⌘⌥E reaches References
   anywhere (lens rule) and a dead pin-click would be silent failure — but
   §6.2 designed the column for Author, in Plan it takes 260–620 pt from the
   canvas §8A.3 protects, and Publish gets a study column its registry never
   offers. Both sides are written up in the merge history (Plan 2
   final review). If ruled against: the clean cut is a persona input to
   `AssistantColumn.isPresented`, not dismiss-on-switch.
2. **Strip freshness for closed statements.** An answer appended to a
   statement no pane has open reaches the strip only on the next re-render
   (`derivedCache` is observation-ignored). The honest doc clause shipped;
   whether to build an invalidation mechanism is open.

## Smoke — owed now, none run by a human

**The loop (dev app, real claude):**
1. Open a novel in Author, type a paragraph, ⌘R — the "Checking…" flash, then
   notes in ⌘⌥D within seconds. Fix a flagged paragraph → its note dismisses
   itself. ⌘R again → the old notes are replaced.
2. **From the launched `.app`, not xcodebuild** — the CLI must be found (GUI
   PATH is the untestable seam; `~/.local/bin` probe + login-shell fallback).
3. ⌘R with the project row selected → nothing, no flash. ⌘R twice with no
   typing → "Nothing new since the last check.", no API call.
4. Turn the AI toggle off mid-run → no red banner, and `ps aux | grep claude`
   shows no orphan. Close the window mid-run → same.
5. Promote a note → a ¶-anchored task in Tasks; ⌘Z removes the task and the
   note stays gone (intended). Answer a note → the paragraph is in the piece's
   intent (Intent pane), and a re-run reads it.
6. Gear → Deep → next run pauses once (cold start, expected) and answers on
   the new model.
7. Not logged in / CLI missing states read honestly in the pane header.

**The surfaces:**
8. The strip: appears over the prose when the piece has intent, without a
   save; ⌘\ hides it; ⌘1/⌘3/⌘4 → absent; no intent → absent.
9. ⌘⌥E: pins from linked research AND canvas clusters; click → column; Esc /
   click-again dismisses; drag the resize handle; width survives quit→reopen;
   switching chapters dismisses the studied pin.
10. Escape composition in Plan: dim the board (select a chapter), study a pin
    — first Escape takes the column, second leaves the dim. In ⌘⇧F, Escape
    exits focus and does NOT silently discard a studied pin.
11. Canvas highlight: a loose card bound to a chapter by its own Piece picker
    now lights with that chapter's dim (the widening — new, decided).
12. Unread badge: run with the pane closed → dim accent badge; in Author open
    Inbox via ⌘⌥B beside it → two badges render.
