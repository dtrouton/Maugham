## Six things that will bite c3 specifically

1. **Adding a tool breaks more literals than you expect.** The count is **52** today (`MCPToolCatalog.all`). Both docs literals are real — `CLAUDE.md`'s `**52 tools**` and `Maugham/MCP/AREA.md`'s `## Tool catalogue (52)` — **plus a prose occurrence in `AREA.md` that `DocSyncTests` cannot see**, because it matches on `firstMatch`. `grep -n "52" Maugham/MCP/AREA.md` and fix every hit. A new tool breaks at least three tools-list tests.
2. **The sidecar is at schema 6**, not 4 as the old draft assumed (4 = `promotedItemID`, 5 = `boundPieceID`, 6 = `contributedToItemID`). c3's `author` field is its own bump to **7**, additive-optional both ways, and **must not fold in anyone else's**. When you bump, `grep` every schema literal in the canvas test tree — and check the "from the future" fixture, which has needed rebumping at *every* bump so far or it stops exercising the refuse-a-newer-schema path.
3. **Tripwire 32's census now expects FOUR entries** — `LineInspector.swift`, `PromotionPerformer.swift`, `RegionInspector.swift`, `ScrapInspector.swift`. A write tool that touches the scene makes a fifth, **must** use `mutateFromInspector`, and **must** join the expectation by name in the same commit. This is the sharpest instance: an MCP write arriving while the writer holds "Edit Scrap" open registers no undo step of its own and rides into the writer's next sentence.
4. **`CanvasRenderer.lineLabelBox` trims `.whitespaces`** where everything else trims `.whitespacesAndNewlines`, so a `"\n"` label draws an empty pill. Unreachable today — **c3 is the first slice that can write a label without passing `LineInspector.normalise`**, since the codec does not normalise on load. Normalise at your boundary or widen the renderer first.
5. **The reproduction corollary is structural, not advisory** (§8A.2 constraint 2). The photo stays on the canvas and what Claude derives from it is visibly tied to it; derived nodes must never land loose where their origin is unrecoverable. And constraint 1: Claude-created nodes are visibly marked, reusing `AnnotationAuthor.SourceKind` (`SpanAnchor.swift:23`) rather than minting a second provenance enum.
6. **`MCPTool` is `static var method` / `description` / `inputSchemaJSON` and `@MainActor static func handle(paramsJSON:registry:)`.** There is no `name` and no `run(projectRoot:)`. `decodeParams`/`resolveProject` are protocol-extension helpers (`MCPToolHelpers.swift`); an unknown project throws `MCPError.unknownProjectID`, not `invalidArgument`.

## How to write the plan — the lesson this session actually paid for

**The plan's own draft code was the single largest source of defects.** Every task's implementation was transcribed from the plan, and the reviews then found, in the plan's code: a preview that said "Goes to: research/" while the mode picker said "Rewrite" (§6.1's whole promise, broken on the one path that matters); `readBody`'s `?? ""` turning a read failure into a truncating write on three append paths; a missing `flushPendingSave` on the palette path; and four assertions that passed for the wrong reason. Not one was the implementer's error.

So: **state the requirement, the symptom and the verified signature — and let the implementer write the code against the real file.** Where the old plan gave a whole function body, give the contract and the failure it must not have. Where you do state a fact, name the file and line you checked it against.

Three more, each paid for:

- **Every negative assertion needs its disable experiment**: remove the guard, watch the test fail, restore it, and report the output. Six assertions across these slices passed for the wrong reason until this was done, and *two* were caught only because an implementer ran the experiment on a test it had merely transcribed.
- **Budget for the whole-branch review, and give it the ledger.** It found a Critical or a cross-surface contradiction in *every* slice: an untyped mark that let a second promotion destroy a palette card; a region told "Became the palette card" when it became a note, with `AREA.md` asserting the copy was already safe; a confirmation banner contradicting its own preview one second earlier. None was visible to a per-task reviewer.
- **Read the tree after any abnormally-ended run.** Two agents were cut off mid-task here; one left a **planted defect** in the working tree — the exact fallback that would have let a contributor rewrite a joint note — with its own comment admitting it. Uncommitted, but nothing would have failed.

## Constraints that will otherwise be rediscovered

- **`ProjectWindow.body` has a zero expression budget.** Window-level behaviour goes in an extracted `ViewModifier`, applied in one line.
- **A `store` is never read from a view `body` or anything `body` calls.** Deferred closures (`artifactTitle`, `pieceTitle`, `paletteSwatchHexes`) are the pattern.
- **A `.keyWindow` post from inside a sheet or dialog is DROPPED** — the v0.24.0 bug, recorded in `TranslationReviewModifier`.
- **`CanvasView.swift` has five source-layout contracts** in its header, enforced by tests that slice the file as text. Contract 1 *crashes* rather than fails; contract 5 fails if certain accessibility modifiers are named **in a comment**.
- **Which SwiftUI arm renders cannot be asserted** — put the decision on the model as a value. But **a line's presence can** be: the raw-source census with a planted-offender companion is this directory's instrument, now used five times.
- Run `xcodebuild` in the **foreground**, one at a time. **Never dispatch two implementers at once**; they share the working tree. `-only-testing` takes `MaughamTests/<ClassName>`, **never a folder path**.
- `./gen.sh` after adding any file. **Never commit anything under `Maugham.xcodeproj/`.**
- **Nothing guards `Maugham/Canvas/AREA.md`.** Every count in it is prose, and a wrong one has survived three review passes twice. Count the array, not the sentence.
