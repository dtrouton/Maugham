## Process lessons from this run

- **Worktree-isolated sessions refuse compound shell commands** (`for … done`, `&&` chains with `cd`/`git`, pipelines with `$(…)`); split into plain commands, or write a script under the SDD workspace and run it.
- **Batching same-shape transcription tasks worked** (Tasks 4–6 in one sonnet dispatch, one review): three pure files, 28 tests, zero findings.
- **A nested type of a `@MainActor` class does NOT inherit the isolation** (Task 1's `Confinement` needed its own `@MainActor` to read `sessionConfigDirectory`); a test spy conforming to a `@MainActor` protocol DOES need `@MainActor` on the class (Task 2) — the plan's literal test code omitted it twice.
- **Plan defects the executors caught**: mid-line `<!-- ¶id -->` anchors in test fixtures (`stripAnchors` is whole-line); `try XCTUnwrap(await …)` (async in an autoclosure); the brief's `@MainActor enum TranslatorsNote` (pre-empted by a controller ruling). All fixture/annotation-level; no production code diverged from the plan except by ruling.
- **Haiku task reviews were sufficient for transcription tasks; the opus whole-branch review found what they could not**: a missing test pin on the one window arm that makes the keystroke work, an argv shape never run against the real CLI, and a comment that was false for the preset languages. Same lesson as P1 — keep the whole-branch review on the top model.
- **Read the kept xcresult** — gate 1's `exit=65` was one flaky click test, not the branch; gate 2's `exit=0` agreed with its xcresult.
