### 3.2 Two-loops / two-readers — one two-map collision (new this window)

- **G1 [Low] A round's editor-presence is guarded once (before the async burst-flush hop) and not re-asserted after it, so a stage cleared mid-hop yields a degraded *passless* round instead of a refusal.** `runRequested` refuses a round with no editor at `CompilerOrchestrator.swift:679-682` (`reader(docId,.round) == nil` → `.noEditor`). That refusal is **above** the `Task { await environment.prepareForRun(docId) }` hop (`:707-708`). The post-hop re-ask block (`:711-716`) deliberately re-checks the window, Claude-toggle, and reading — but **not** the round's editor. `beginRun` then re-resolves `activePass = reader(docId, kind)` at `:847` under the comment (`:843-846`) that "a round with no editor never reaches here… `nil` at this point is always a check with a vacated seat" — a guarantee by same-actor timing, not by construction. If the writer clears the piece's active pass during the hop, `activePass == nil`, `passId = kind == .round ? activePass?.id : nil` → nil (`:854`), `round` → nil (`:858`): the run proceeds **unnumbered, stamped `.round`, notes signed "Claude" and unstamped**. **Not** the tripwire-34 regression (the marker is never read or moved by a round; a check can never acquire a passId — both structural), so the blast radius is a degraded round, not a corrupted lane. **Flagged independently by the tracer (as a finding) and the bug-hunt (as an "invariant assumed… guaranteed by timing, not construction")** — a genuine map collision. — `Maugham/Compiler/CompilerOrchestrator.swift:711-719, 843-854` — fix-shape: in the post-hop re-ask block, re-assert `kind == .round && reader(docId,.round) == nil` and abort with `.noEditor` instead of falling through — effort: S.

### 3.3 Doc comments left stale by the two-loops rework (new this window)

- **G2 [Low] `DiagnosticsStore.lastRun`'s doc names a reader that no longer exists.** Lines 623-631 say `lastRun` (newer-of-the-two) exists for "`IntentDrift.mayTrailDraft`… and the unread badge, which counts what any finished run left the writer unread." After the per-slot badge change (whole-branch Ruling 9), the unread badge is answered by `unreadCount(docId:, kind:.check)` reading the `.check` slot directly, never through `lastRun`; `lastRun` now has exactly one production caller, the intent-drift strip (`ProjectWindow.swift:1472`). — `Maugham/Compiler/DiagnosticsStore.swift:623-631` — fix-shape: drop the "unread badge" clause, leave `IntentDrift.mayTrailDraft` as the sole named reader — effort: S.
- **G3 [Low] Two doc examples describe a draft-stage word rendering on a round's lane line, which is now impossible.** `DraftStage.laneWord`'s doc gives "Le Guin · round 3 · drafting" (`DraftStage.swift:38`) and `LetterSection.signature`'s doc says "Review's lane line carries the same word" (`LetterSection.swift:325-328`). But a round derives `stage = nil` (two-loops P1 doses checks alone), so `signature` renders no stage word when `round != nil` and `ReviewRoundCockpit.laneLine` names no stage — a run has *either* a round (stage nil) *or* a stage (round nil, a check files in no lane), never both; the three-part string cannot occur. The code is correct; the two comments survived from editorial-letter P3. — fix-shape: correct the example to a check's form ("Le Guin · drafting") and drop the "Review's lane line carries the same word" clause — effort: S.

### 3.4 Unenforced-but-guaranteed key invariant (new this window)

- **G4 [Low] `askKey` joins `docId#kind` with `#` and the legacy-ask migration assumes no docId contains `#`.** `loadAsks` treats any key containing `#` as new-format and any bare key as a legacy `.check` ask (`DiagnosticsStore.swift:979-983`); `askKey` is the only place the two are joined (`:764`). A docId containing `#` would both mis-key on write and be mis-migrated on read. Globally guaranteed safe today — docIds are `d_`-prefixed, alphabet-restricted ids (tripwires 8/18), and no untrusted source of docIds reaches `askKey` — so this is a local re-assert of an already-global invariant, not a live bug. Flagged by both the tracer and the bug-hunt maps. — `Maugham/Compiler/DiagnosticsStore.swift:764, 979-983` — fix-shape: assert the docId charset at the key boundary (turn a silent mis-key into a loud failure if the docId format ever changes) — effort: S.
