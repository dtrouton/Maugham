## Conventions that bit TODAY (additions to the 30-handoff's list, which all still stand)

- **A package-only task must run `./scripts/test.sh` before calling itself done** — grep
  tripwires (ADR-0018 annotations, the writer-copy census) live in the Mac scheme; two
  subagent tasks shipped red Mac tripwires by running only `swift test`. Bit twice in one day.
- **`// adr-0018-ok:` and its census siblings match ON THE OFFENDING LINE** — a comment on
  the line above does nothing.
- **A concurrency/Sendable diagnostic on a file you just wrote is real** even though the
  package builds clean — MaughamCore is swift-tools 5.10 without strict-concurrency, so
  `@MainActor`-isolation errors surface only under `-strict-concurrency=complete`. (Whole-
  branch candidate someday: turn the flag on for the package.)
- **origin/main moves under you** — three sessions push to it. `git pull --ff-only` before
  any merge, and read the PUSH RANGE on the way out: an interleaved commit means the merged
  composition was never gated together (docs-only interleaves are fine; code interleaves get
  a post-merge gate). A fetchless merge that no-ops silently is the worst kind of clean.
- **Verify subagent-reported test counts against the file** (`grep -c "func test_"`) — one
  implementer under-reported two suites from memory; the counts were fine, but only a
  reviewer's independent run proved it.
- **The writer-copy census** (`TripwireGrepTests`, "quarantine" in writer-visible strings
  under `Maugham/Views/` + `EditorSurface.swift`) is new today and WILL fire on new view
