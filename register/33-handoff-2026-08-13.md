## Conventions that bit today (additions to prior handoffs)

- **The flip tool's re-dump can drop filings** if the file was mid-edit: my first
  41-entry filings write lost the 032-036 block (contiguous), caught only by
  eyeballing `flip-claim.py recompute`'s "over 36". After any flip/recompute,
  assert `filings == claims` count (a one-liner) before trusting it.

  a nil-guard does not detect unreadability; use `isReadableFile`. (Cost one RED

  refs-vs-test-names with a cross-check script during promotion; do that again
  after any test rename.
