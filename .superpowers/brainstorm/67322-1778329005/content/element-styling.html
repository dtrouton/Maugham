defaults baked into this mockup

  • Indents (in monospace chars from the body's left margin): Character = 17ch, Parenthetical = 13ch, Dialogue = 9ch (max width 35ch), Action = 0ch (full width), Transition = right-aligned, Centered = horizontally centered.
  • Scene Headings: bold, no underline. Underlined sluglines are a stylistic option — some scripts use them, most don't. We default off.
  • Sections (#) render as bold + underlined — they're structural markers (often acts) and the writer wants them obvious.
  • Synopses (=) render dim italic — they're notes-to-self about a beat, not script content.
  • Boneyard (/* … */) and Notes ([[ … ]]) render dim italic in-place — visible to the writer, visually quiet, NOT counted in page count.
  • Page break (===) renders as a faint dashed rule.

The one decision: forced-character casing

The source has @Sam (forced character, mixed case). How should the editor render forced-syntax lines that aren't ALL CAPS in the source?

A

Preserve as typed

Render @Sam as "Sam" — keep source = display. Cursor positions match what the writer sees on screen.

Simpler. Some Fountain editors do this. Writer who wanted uppercase would have just typed it that way.

B

Visually uppercase

Render @Sam as "SAM" via NSAttributedString glyph transform. Source stays mixed-case on disk.

Matches Final Draft / Highland convention. Slightly trickier (cursor + selection handling around transformed glyphs in NSTextView).
