# Welcome to Maugham

This is a real project — edit anything, or delete it when you're done. Nothing here is special-cased: it behaves exactly like a project you create yourself.

Everything you type autosaves as plain text on disk. There is no separate "save" step to remember. Press ⌘S whenever you like — it drops a labeled checkpoint you can return to later, but your words are already safe.

Try it: put your cursor at the end of this line and write a sentence.

When you're ready, open the next chapter, "Try It," from the binder on the left.
