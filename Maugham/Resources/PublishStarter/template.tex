% Barebones publish template.

% contract. It renders correctly but is DELIBERATELY plain — Computer
% Modern, no drop caps, no ornaments — so it explicitly invites redesign.

% project its own typographic identity.
%
% Language editions: if this template \input's partials (preamble/frontmatter/
% backmatter), give the edition its own template.<lang>.tex whose \input lines
% point at the <lang> partial variants — the resolver picks the template
% variant, and everything else follows from it.

\input{prose}

% without going through Maugham.
